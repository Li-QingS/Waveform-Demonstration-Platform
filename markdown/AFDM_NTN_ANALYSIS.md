# AFDM 星地链路升级与研究口径

更新日期：2026-11-04。

AFDM 页面沿用 OFDM、OTFS 的“星地场景 → 波形与接收 → 性能研究”操作流程，保留平台现有 Fusion 浅色控件和 MATLAB 配色。实时与扫描共用确定性数值模型，实验配置与结果一起导出。

## 1. 旧页的问题与本次范围

旧页使用固定网格和通用三径信道，chirp 参数只读；参数采用 `exp(-j 2π c n²/M)` 的旧归一化定义。页面没有明确的 CPP 选择、完整星地场景、可复现的 chirp 扫描或接收机先验说明。停止时还会清空已有图形和统计。

新版加入 NTN 时延/功率轮廓、S/Ka/AWGN 预设、公共轨道预补偿与独立散射多普勒、分数时延、可编辑 chirp、CPP/CP、数据块数和完整研究快照。停止、切页保留结果，返回后需手动启动；运行时锁定实验参数，实时与扫描互斥，超时未退出的线程仍归原任务管理。

这里只更换独立 AFDM 软件研究页的模型。硬件链路、旧兼容收发机和三波形配对引擎有各自的信号约定，不把新参数默默写入那些模块。

## 2. DAFT 参数和前缀

研究模型使用标准 DAFT 约定：

```text
A = Λ(c2) F Λ(c1)
Λ(c)[n,n] = exp(-j 2π c n²)
s = Aᴴ x
```

M 是变换点数，x 是 DAFT 域 QAM。旧模型的同名参数多除了一次 M，因而同样的 `0.05` 不是同一条 chirp；旧参数换算为本页口径应为 `c_new = c_old / M`。本页控件、导出和脚本都采用新定义。

CPP 的负下标样本为：

```text
s[n] = s[M+n] × exp(-j 2π c1 (M²+2Mn)), n=-L,...,-1
```

这些变换及前缀定义依据 [Bemani 等，AFDM 原始论文，式 (16)、(18)、(19)](https://arxiv.org/pdf/2204.12798#page=8)。当 M 为偶数且 `2 M c1` 为整数时，整数采样位置的 CPP 恰好等于 CP；不能仅从默认参数截图中看不出相位差就认为 CPP 没有实现。任意手动 c1 则需实际应用该相位修正。

默认 M=64、8 个数据块、前缀 16、30 kHz、QPSK，`c1=3/(2×64)`、`c2=1/(64²√2)`、CPP。采用较小的网格控制完整矩阵均衡的计算成本。参数建议功能只是依据当前网格和配置边界给出可检查的建议，不是根据真实 BER 自动挑选最优参数，也不是全分集保证。

## 3. 实际发射、信道和接收

每个突发包括前保护段、一个已知全带宽 OFDM 训练块、多个 IDAFT 数据块和后保护段。训练使用普通 CP，数据使用选定的 CPP 或 CP。训练能量、所有前缀能量均计入：

```text
噪声方差 = 发射突发实际能量 / (信息比特数 × 10^(Eb/N0 / 10))
```

静默保护段只增加时间、不增加发送能量。噪声不按接收衰落逐帧归一化。物理路径使用与 OFDM/OTFS 同一张 NTN 表、同一固定种子幅度与初相生成逻辑，各径多普勒按连续仿真采样时间旋转。公共轨道频移预补偿和散射扩展分开设置。

分数时延作用于 IDAFT 后实际时域样本的 Nyquist Fourier 插值，而非在采样间隙另行增加未观测到的高频二次 chirp。CPP 负时间段按其实际相位校正构造，频率分量折回 Nyquist 区间；保留源块的有限线性边界。默认 CPP 与 CP 的发射采样相同，分数时延信道输出也应相同。任意 c1 的前缀仍实际包含相位修正。前缀不足时，前块尾部能量进入后块，不能自动绕回同一块。这个逐块脉冲插值模型不等于完整射频滤波、过采样重建或标准 3GPP 仿真器。

| 策略 | 信道信息与处理 |
| --- | --- |
| 训练 LS | 由已知训练块估计静态循环信道，以全 M 滞后及 CPP 包裹相位构造近似完整块矩阵；估计在数据段保持，采用完整块 LMMSE/ZF |
| 理想 CSI 参考 | 知道实际数据块内的时变信道矩阵与残余公共 CFO；采用相同完整块 LMMSE/ZF |
| 关闭预补偿 + LS | 公共轨道预补偿比例置零，仍执行训练估计与完整块均衡 |

载荷比特只用于计分，不能作为训练或估计信道的输入。训练估计 IFFT 后的噪声或分数时延分量可分布于全 M 滞后，循环近似会对真实有限前缀之外作延拓；这属于估计模型误差，不能当作已准确识别物理路径。理想参考只知道本块对本块的作用，未联合反演整个突发，也不会先验减掉其他块的未知数据干扰。MMSE 使用已知仿真噪声方差；ZF 在病态信道可能放大噪声。

AFDM 的有效 DAFT 信道一般存在非对角耦合，因此本页使用完整块矩阵均衡，不能把它简单标为“DAFT 单抽头即可消除多普勒”。训练估计的静态近似在大残余 CFO、较强路径动态或长数据段下可能老化；完整矩阵的规模不意味着信道信息自动变得准确。

实时第四图显示所选来源的有效 DAFT 信道矩阵幅度，并明确标注训练估计或理想真值参考。它不是接收星座能量图，也不是自动检测出的物理散射地图。

## 4. 性能研究和结果解释

支持 Eb/N0、额外残余 CFO、散射多普勒、子载波间隔、时延缩放、c1、c2 与数据块数扫描。每点三种策略复用发送比特、路径和单位噪声；实际发射能量决定噪声方差。改变 chirp 时，前缀的实际能量也可能改变，脚本按同一发送 Eb/N0 定义重新计算噪声。

统计使用真实 `错误比特 / 总信息比特`、FER、参考能量加权 RMS EVM 与双侧 95% Wilson 区间。零误码保存为 `0/N`，对数图另画区间上界，不能当成非零实测 BER。不强制曲线单调，也不把 BER 截到 0.5。

取消扫描只保留已完成全部帧预算和三策略的完整点。导出保存运行时配置、原始计数、完成/取消/失败状态和模型假设；之后改动控件不能重新标注旧实验。

以下限制与解读直接影响结论：

- 理想 CSI 已知公共残余频偏，完整矩阵均衡可消除本块内部耦合。该曲线对 CFO 较稳健，不能证明实际接收机已实现同样的频偏捕获和跟踪能力。
- c1/c2 扫描观察的是所选路径、前缀、接收机和能量预算下的条件性结果。分数时延/多普勒、有限精度建议、线性检测和全载荷资源，不直接满足论文全部分集证明条件。
- 固定 M 改变子载波间隔，同时改变带宽、前缀时长和突发时长；改变数据块数，同时改变训练占比、信息比特预算及估计老化时间。
- 缩放时延是压力测试，不能当成新的标准剖面。前缀不足、信道估计误差、时变和矩阵噪声增强可能共同影响 BER。
- 一次固定种子试验不是多衰落平均。Wilson 区间是条件性计数近似，相关误差不等于独立信道覆盖概率。

当前模型假设辅助帧定时已知、未编码 SISO；不包含盲频偏/定时捕获、完整 Jakes 统计、FEC/HARQ、功放、相噪或传播链路预算。每个突发独立生成，包含突发内跨块 ISI，不包含跨突发尾迹记忆。

## 5. 与 OFDM、OTFS 和对比页的关系

三个独立研究页对齐场景输入、统计定义与操作流程。OFDM 的梳状导频单抽头接收、OTFS 的帧首训练 TF 单抽头接收、AFDM 的训练估计完整块接收，所用资源、估计与计算预算不同，不能把三页 BER 排序直接解释成波形固有优劣。

需要同资源横向对比时，应使用“波形对比”页，核对其通用三径、相同发送能量与理想 CSI 完整 LMMSE 的配置。对比页已支持标准相位口径的 c1/c2 编辑，与本页参数定义一致；但仍采用普通 CP 和不同资源、信道与接收机预算，不能因为 c1/c2 相同就把两个页面的曲线视作同一实验。FDIDM 保留独立的软波形与自适应研究逻辑。

## 7. 本次实际复现的条件性结果

已运行上述命令，完成八类研究、34 个扫描点，每点每策略 20 帧。原始输出可运行复现命令后在本机生成的 `output/afdm-ntn-study.json` 中查看；运行产物不随源码提交。默认 C5-200、2 GHz、28080 km/h、径向投影 0.5、99.9% 公共预补偿、64 点 DAFT、8 数据块、16 点 CPP、30 kHz、QPSK、seed=42、完整矩阵 MMSE。采样率 1.92 MHz、突发 752 采样（约 0.3917 ms），CPP 时长约 8.333 μs；每点每策略统计 20480 个信息比特。

| 条件 | 训练 LS 错误/比特 | 训练 LS BER | 理想块内 CSI BER |
| --- | --- | --- | --- |
| Eb/N0=12 dB | 374/20480 | 0.0182617 | 0.00209961 |
| Eb/N0=20 dB | 2/20480 | 0.0000976563 | 0 |
| 20 dB，额外残余 CFO=300 Hz | 504/20480 | 0.0246094 | 0 |
| 20 dB，额外残余 CFO=1500 Hz | 11744/20480 | 0.5734375 | 0 |
| 20 dB，散射扩展=1200 Hz | 119/20480 | 0.00581055 | 0 |
| 20 dB，散射扩展=4800 Hz | 1376/20480 | 0.0671875 | 0 |

默认 20 dB 训练 LS 的 Wilson 区间约为 `[2.6781e-5, 3.5603e-4]`。理想参考 `0/20480` 的上限约 `1.8754e-4`，不是无误码保证。关闭公共预补偿时默认 20 dB 得到 `10272/20480 = 0.50156`。

理想参考在额外 CFO=15000 Hz 下仍得到零误码，是因为它先验知道包含该 CFO 的完整块内矩阵。这不意味着训练接收机或实际设备已经实现 15 kHz 的盲捕获。训练 LS 在 1500 Hz 时 BER 超过 0.5，是静态估计与持续相位旋转失配下的真实计数，不进行人为截断。

chirp 扫描在默认 20 dB 条件下，c1=0 得到 `0/20480`，c1=0.0234375 得到 `2/20480`。二者区间明显重叠，不足以证明前者总体更优，更不能凭这个单种子低错误数结果宣称参数建议已经找到最优 chirp。建议参数只提供结构上的工程起点。

A100 时延缩放 50 倍时最大超额时延 14.25 μs，超过 8.333 μs 前缀；训练 LS 得到 `390/20480`，理想块内参考得到 `6/20480`。前缀不足、估计误差与时变共同作用，不能把全部性能差只归因于其中一项。上述结果反映所选路径实现和接收机，不直接对应 OFDM/OTFS 页的资源预算或完整 NR 性能。
