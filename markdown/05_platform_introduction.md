# FDIDM 软波形自适应演示平台介绍

> 本文档从通信项目的角度介绍本平台：研究问题、系统组成、通信链路、参数设置、观测指标与典型使用流程。

## 1. 平台定位

本平台是一套面向**卫星-地面一体化通信**场景的波形研究、演示与验证平台，基于论文
*Fractional Dual Index Division Multiplexing: A Soft Waveform Design Toward Integrated Satellite-Terrestrial Networks* 开发。

平台以 **FDIDM（分数阶双索引复用）** 波形为核心，同时支持 OFDM、OTFS、AFDM 三种对比波形，形成从"算法仿真 → 链路级 Monte-Carlo 对比 → USRP 硬件实测"的完整研究闭环。

核心研究问题：

- 在 LEO 卫星通信的高多普勒、大时延、快时变信道下，不同波形的误码性能差异；
- FDIDM 的可调分数阶指数 α、β 如何随信道自适应，以覆盖 OFDM（α=β=0）与 OTFS（α=β=1）之间的连续波形族；
- 软件仿真结论能否在真实 USRP/RF 链路上复现，以及真实链路下的工程问题（同步、CFO、信道估计、实时处理稳定性）。

## 2. 系统组成

### 2.1 功能页签

| 页签 | 功能 |
| --- | --- |
| FDIDM 波形仿真 | 矩阵化 FDIDM 收发链路，支持 α/β 搜索、理论 SER 与实测 BER/EVM 对照 |
| OFDM / OTFS / AFDM 波形仿真 | 各波形的工程接收机仿真（同步、CFO 校正、信道估计、均衡） |
| FDIDM 硬件验证 | FDIDM + USRP 实测，含 FEC、多种信道估计器、α/β 信道自适应、调试日志 |
| 硬件测评 | OFDM / OTFS / AFDM 通用 USRP 硬件测评页 |
| 波形对比分析 | 实时双波形对比 + 独立 Monte-Carlo 扫描（BER-CFO、BER-Doppler 曲线） |

### 2.2 代码结构

```text
waveform_sim/
  main.py                  # 程序入口（PyQt5 主窗口）
  ui/                      # GUI 页面
  simulation/              # 纯软件仿真后端
    simple_fdidm_rx.py     # FDIDM 矩阵化演示链路
    simple_ofdm_rx.py      # OFDM 收发链路
    simple_otfs_rx.py      # OTFS 收发链路
    simple_afdm_rx.py      # AFDM 收发链路
    compare_scan_backend.py# 统一 Monte-Carlo 对比扫描后端
  hardware/                # USRP/GNU Radio 硬件后端
    fdidm_hardtest.py      # FDIDM 硬件链路（同步/CFO/信道估计/均衡/FEC/αβ自适应）
    ofdm_hardtest.py       # OFDM 硬件测试
    otfs_hardtest.py       # OTFS 硬件测试
    afdm_hardtest.py       # AFDM 硬件测试
markdown/                  # 设计、评审、调优与 TODO 文档
```

### 2.3 运行与依赖

```powershell
cd waveform_sim
python main.py
```

- 基础依赖：Python 3.11+、NumPy、PyQt5、pyqtgraph；
- 硬件链路还需：GNU Radio / UHD、USRP B210（兼容 N210 / X310）；
- 没有硬件时，软件仿真页与波形对比页可独立运行。

## 3. 通信链路与信号流程

### 3.1 发射端

```text
应用层数据（文本载荷）
  → 帧封装（帧头 + 载荷 + CRC）
  → 信道编码（FDIDM 硬件链路：卷积编码 + 比特交织）
  → 比特映射（QPSK / 16QAM / 64QAM）
  → 资源网格填充（导频 + 数据）
  → 波形变换
      FDIDM：IFDIT（分数阶双索引变换）+ Heisenberg 调制
      OFDM ：IFFT + 循环前缀
      OTFS ：时延-多普勒域 → 时频域变换
      AFDM ：仿射傅里叶变换（DAFT，chirp 参数 c1/c2）
  → 帧结构组装（同步前导 + 训练/导频单元 + 数据单元 + 保护间隔）
  → 基带波形（重复成适合 UHD 的长波形）→ USRP 发射
```

### 3.2 接收端

```text
USRP 接收
  → 粗同步（重复半段前导相关峰，Schmidl-Cox 类方法）
  → CFO 估计与校正（前导粗估 + 导频残余精估，可选多候选扫描）
  → 信道估计
      full_htf ：论文式全矩阵 H_TF 估计
      diag_tf  ：对角时频域快速诊断估计
      tdl_param：软件 TDL 参数化基估计
  → 均衡（ZF / MMSE）
  → 符号解映射 → 解交织 → 卷积译码 → CRC 校验
  → 统计输出：BER、EVM、同步指标、CFO、信道质量、解码状态
```

### 3.3 帧结构要点

- 同步前导：重复半段结构，用于粗同步与 CFO 估计；
- 训练/导频：用于信道估计与残余相位/增益修正；
- 数据单元：承载编码后的 QAM 符号；
- 保护间隔：吸收时延扩展，避免帧间干扰。

## 4. 参数设置说明

### 4.1 波形结构参数

| 参数 | 含义 | 默认值 / 范围 | 说明 |
| --- | --- | --- | --- |
| M | 时延维大小（FDIDM）/ 子载波数 | FDIDM 硬件：16（4~64）；OTFS/AFDM：64 | 决定资源网格的一维尺寸 |
| N | 多普勒维大小（FDIDM）/ 符号数 | FDIDM 硬件：16（1~64）；OTFS：8；AFDM：7 | 与 M 一起构成 M×N 资源网格 |
| CP 长度 | 循环前缀长度 | FDIDM：4（0~M-1）；OFDM/OTFS/AFDM：16 | 需大于信道时延扩展，否则产生符号间干扰 |
| α、β | FDIDM 分数阶指数 | 硬件页：0.5 / 1.0（范围 -2~2）；仿真页默认 0/0 | α=β=0 → OFDM，α=β=1 → OTFS，中间值为 FDIDM |
| 搜索步长 | 仿真页 α/β 网格搜索步长 | 0.1（0.1~0.5） | 越小搜索越细、计算越慢 |
| 帧数 / 保护间隔 | 一次发送的帧数与帧间保护采样数 | 4 帧 / 64 采样 | 影响吞吐与抗帧间干扰能力 |

### 4.2 调制、编码与均衡

| 参数 | 含义 | 默认值 / 可选值 |
| --- | --- | --- |
| 调制阶数 mod_order | QAM 星座 | QPSK（2 bit/符号）、16QAM（4 bit）、64QAM（6 bit） |
| 均衡器 equalizer | 接收端线性均衡算法 | MMSE（默认）、ZF |
| 编码方案 coding_scheme | FDIDM 硬件链路前向纠错 | 可选卷积编码（可关闭） |
| 交织 coding_interleaver | 比特级交织 | 开 / 关，配合卷积码抗突发错误 |
| 发射文本 tx_text | 实际发送的载荷内容 | 任意文本，接收端显示并做 CRC/字节匹配 |

### 4.3 仿真信道参数

| 参数 | 含义 | 默认值 / 范围 | 说明 |
| --- | --- | --- | --- |
| SNR / Eb-N0 / Es-N0 | 噪声条件 | 仿真页默认 10 dB | FDIDM 仿真支持 Eb/N0 与 Es/N0 两种定义 |
| CFO（载波频偏） | 发射接收间的频率偏移 | 默认 0 Hz，可调 | 评估波形对频偏的鲁棒性 |
| Doppler 频偏/扩展 | 多普勒频移或扩展 | 仿真页默认 20 Hz | OTFS/AFDM 相对 OFDM 的优势通常在此体现 |
| 时延扩展 | 多径时延范围 | 0~若干采样，可调 | 需与 CP 匹配 |
| 信道模型 | 多径统计模型 | FDIDM 仿真：TDL-C | 3 径稀疏时变信道为主 |
| 速度 / 多普勒径向因子 | LEO 场景速度建模 | 28080 km/h / 0.10 | 径向投影因子避免多普勒过大失真 |
| 信道随机种子 | 随机信道复现 | 42 | 相同种子可复现实验 |
| 动态信道模式 | 信道随时间变化方式 | fixed / block / fast | 分别对应静态、按帧变化、快时变 |

### 4.4 硬件射频参数

| 参数 | 含义 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 中心频率 carrier_freq | USRP 射频载波 | 2.4 GHz | 需在设备支持范围内，注意频率许可与安全 |
| 采样率 samp_rate | 基带采样率 | FDIDM：1 MHz；OFDM/OTFS/AFDM：960 kHz | 1 MHz 为 B210 52 MHz 时钟的整数分频，更稳定 |
| TX 增益 / RX 增益 | 射频收发增益 | FDIDM：20 dB；其余：40 dB | 回环测试建议从低增益开始，防饱和 |
| 天线 | 收发天线端口 | TX/RX、RX2 | 回环测试用线缆直连，外场用天线 |
| 设备类型 / 序列号 | USRP 型号与唯一标识 | USRP B210 / 可选 serial | 支持 N210、X310 |
| UHD 缓冲帧数 | USRP streamer 缓冲 | 2048 帧 | 影响 overflow/underflow 稳定性 |
| 发射波形时长/长度 | UHD 友好长波形 | ≥500 ms / ≤1048576 采样 | 避免短波形导致的实时问题 |

### 4.5 接收机算法与稳定性参数

| 参数 | 含义 | 默认值 | 说明 |
| --- | --- | --- | --- |
| channel_estimator | 信道估计器 | full_htf | full_htf / diag_tf / tdl_param |
| full_htf_once | 全矩阵估计是否一次性 | True | 一次性估计减少重算开销 |
| 全矩阵最大阶数 | full H_TF 允许的 M×N | 4096 | 超出则回退轻量估计器 |
| CFO 搜索开关 / 范围 | 多候选 CFO 解模糊 | 开 / ±50 kHz | 高多普勒或晶振偏差大时启用 |
| 残余 CFO 上限 | 导频精估的合理性约束 | 5 kHz | 防止错误估计被接受 |
| 处理节流周期 | Python 解调节流 | 200 ms | 防止 UHD RX overflow |
| 启动稳定时间 | 启动后丢弃脏窗口 | 800 ms | 等待 USRP 收发稳定 |

### 4.6 α/β 信道自适应参数（FDIDM 硬件页）

该功能基于当前信道估计 H_TF，用论文 SER 公式预测各 (α,β) 候选点的性能并推荐最优值。

| 参数 | 含义 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 自适应开关 | 启用/关闭 α/β 优化 | 界面默认勾选 | 后端默认关闭，需要配置开启 |
| 自动应用稳定推荐 | 推荐稳定后自动切换 α/β | 勾选 | 不勾选则只显示推荐 |
| 粗步长 | 第一轮网格步长 | 0.25 | 范围 0.05~1.0 |
| 细步长 | 盆地精化步长 | 0.05 | 范围 0.01~粗步长 |
| 评估间隔 | 相邻两次评估的最小帧间隔 | 8 帧 | 控制计算频率 |
| 稳定次数 | 连续推荐相同点才生效 | 2 | 防止抖动 |
| 最小预测增益 | 切换所需的最低预测改善 | 0.5 dB | 低于此值不切换 |
| 切换冷却 | 应用一次推荐后的冷却帧数 | 16 帧 | 防止频繁重启链路 |
| 整数余量 | 整数点（OFDM/OTFS）优先的 SER 余量 | 0.10 dB | 鼓励退化为简单波形 |
| 最大阶数 | 自适应搜索允许的 M×N | 512 | 超过则跳过搜索 |
| 最小同步指标 | 触发搜索的同步质量下限 | 0.30 | 同步差时不信任 CSI |
| rcond | 矩阵求逆条件数约束 | 1e-6 | 防止病态矩阵 |

### 4.7 波形对比扫描参数

对比扫描使用独立、统一的 Monte-Carlo 后端，保证三种波形在同一物理信道口径下比较：

| 参数 | 含义 | 默认值 |
| --- | --- | --- |
| FFT 长度 | 统一离散系统点数 | 64 |
| 时隙数 | 每帧数据单元数 | 7 |
| CP 长度 | 统一循环前缀 | 16 |
| 子载波间隔 | 统一频率间隔 | 15 kHz（采样率 960 kSa/s） |
| 信道 | 统一 3 径时变多径（0 / 2 / 5 采样延迟，0 / -3.5 / -7 dB） | 固定结构，逐点随机衰落 |
| 扫描轴 | BER-CFO 或 BER-Doppler | 用户设置扫描范围 |
| 固定条件 | 每张曲线固定 SNR、调制阶数、另一轴取值 | 界面设置 |
| 帧数 | 每个扫描点的 Monte-Carlo 帧数 | 界面设置 |
| 波形 | OFDM / OTFS / AFDM 三条曲线 | MATLAB 风格配色 |

## 5. 观测指标与输出

- **BER**：原始比特 BER 与 FEC 译码后 BER，支持历史曲线与实时估计；
- **EVM**：瞬时 EVM 与滑动平均 EVM，用于星座质量评估；
- **星座图**：均衡前、均衡后、硬判决、决策整形等多种视角；
- **频谱**：发射/接收基带频谱；
- **同步与 CFO**：同步指标、CFO 估计值及来源（前导/导频/扫描）；
- **信道质量**：HTF 泄漏/NMSE、矩阵条件数、噪声方差、TDL 拟合误差；
- **解码状态**：CRC 是否通过、字节匹配数、解码成功率；
- **α/β 性能面**：实测 EVM/BER 在不同 (α,β) 下的冻结统计柱面；
- **调试日志**：环形缓冲区 + 文件导出，含参数上下文、估计器、同步、CFO、BER/EVM 等全链路信息；
- **实验快照**：当前参数、状态、指标汇总的 JSON 快照，便于复现实验。

## 6. 典型使用流程

### 6.1 纯软件仿真

1. 启动平台，进入 FDIDM 波形仿真页；
2. 设置 Eb/N0、α/β、调制方式与信道参数；
3. 观察星座图、BER/EVM、理论 SER 曲线；
4. 切换到 OFDM/OTFS/AFDM 仿真页做同信道条件下的横向对照。

### 6.2 波形对比扫描

1. 进入"波形对比分析"页；
2. 设置 SNR、调制阶数、CFO/Doppler 扫描范围；
3. 运行 BER-CFO / BER-Doppler 扫描，对比三条曲线；
4. 用结果判断各波形在不同信道恶化因素下的适用性。

### 6.3 硬件实测

1. 连接 USRP（建议先线缆回环验证）；
2. 在 FDIDM 硬件验证页或通用硬件测评页配置中心频率、采样率、增益、波形参数；
3. 启动链路，观察同步指标、CFO、星座、BER/EVM；
4. 调整增益与估计器，必要时启用 α/β 自适应；
5. 导出调试日志与实验快照，作为实验记录。
