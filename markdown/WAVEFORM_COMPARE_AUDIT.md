# 波形对比页：问题审计与修复

核验日期：2026-11-03。范围是仿真工作区的“波形对比”，包含实时双波形比较和 OFDM / OTFS / AFDM 扫描。

## 已确认的问题

| 原实现 | 影响 | 本次修复 |
| --- | --- | --- |
| 左右分别启动旧收发器，各自独立 RNG、信道、载荷和刷新时钟 | 即使选相同波形，也不是同一批样本；“统一信道”的说明不成立 | 一个后台任务生成完整配对帧，左右原子更新 |
| 扫描 seed 按波形和扫描点偏移 | 不同波形的曲线同时改变信道与噪声，无法隔离波形/参数影响 | 独立的比特、信道、噪声子流；同一 seed / frame_index 在所有波形、扫描点复用 |
| 实时使用旧前导/导频收发器，扫描使用理想 CSI 矩阵接收 | 实时与扫描不是同一统计实验 | 两种模式共用 `WaveformScanSimulator.simulate_frame_set` |
| OFDM 只单抽头，而 OTFS/AFDM 用完整 LMMSE | 曲线差距混入接收机复杂度差异，界面未说明 | 默认统一完整 LMMSE；旧组合仅作为标注清楚的差异演示 |
| 在 TF / DD / DAFT 各域分别保留 48 个数据位置，预留导频却不发送 | 相同符号数不等于相同物理资源占用；预留开销说明失真 | 全部采用 64×7 全载波未编码网格，明确无导频、理想 CSI |
| 只使用循环信道矩阵，却没有实际生成 CP；噪声按各波形接收功率归一化 | CP、能量及衰落统计口径不完整 | 实际生成 CP 和线性时域接收数据；共同发送帧能量与噪声方差；校验 CP 足够 |
| 多层把 BER=0 替换成 1e-6 / 1e-8 | 图上产生并未观察到的误码下限 | 保留原始 0，另用三角标记显示双侧 95% Wilson 上界 |
| 取消仅在点外检查，join 超时后直接丢弃 worker | 旧任务可能继续运算或写入结果；可能留下单波形/半点比较 | 每帧/每波形检查取消；仅发布完整配对帧与完整三波形点；超时保留引用并拒绝重启 |
| 热更新异常被吞掉，旧曲线未统一清空；停止后选波形会直接改旧图标题 | 控件与曲线实际配置可能不一致 | 运行时锁参数；当次配置快照绑定结果与导出；停止后改选择不重标旧图 |

原代码的可控复现例：`scan_axis(seed_base=42)` 两点曾给 OFDM 分配 `[42,142]`、OTFS `[10042,10142]`、AFDM `[20042,20142]`。注入原始 0 BER 后，输出被改成 `1e-8`。在点内发出取消后，旧 worker 仍可提交单波形点，且 `done=False`。这些情形已写成新回归测试。

## 修复后的比较契约

- 固定资源：每帧 64 点 × 7 时隙、15 kHz 子载波间隔、CP 16，共 448 个 QAM 符号。QPSK 每帧 896 个信息比特。
- 三种波形共用比特、三径物理实现、时域单位噪声及同一物理时间轴。调制、通道和噪声使用独立子种子，结果不依赖波形列表或扫描点的遍历顺序。
- 物理信道为 `[0,2,5]` 采样的三径 Rayleigh 块实现，每帧独立抽取增益，帧内按逐径多普勒连续旋转。平均 PDP 归一，不强制每帧接收功率相等。
- 各波形实际发送普通 CP，含 CP 的帧能量归一到同一基准。噪声方差按共同发送能量 / 净信息比特 / Eb/N0 得到，不使用接收衰落幅度重定标。
- 默认接收机等级相同，均为理想 CSI 完整 LMMSE。接收机可利用共同时间域信道分解，再回到各自的单位变换域，避免反复求解大 DD 矩阵。
- OFDM 是 CP-OFDM；OTFS 是矩形脉冲、每时隙普通 CP 的单位变换模型；AFDM 是可配置 c1/c2 的 DAFT 加普通 CP，并非专门 chirp 周期前缀或自适应 AFDM 实现。
- `practical` 模式故意保留 OFDM 单抽头、另两种完整 LMMSE 的差异，界面和导出均标明这包含接收机复杂度差异。
- 每点累计真实错误比特、总比特、错误帧、帧数和 EVM；统计区间是计数区间，不是对所有信道、同步失败或系统中断概率的保证。

**解释边界：**已知公共频偏被包含在理想 CSI 中，完整 LMMSE 可以利用它；因此 CFO 曲线接近并不表示实际同步/频偏捕获无损，也不能要求某条波形曲线天然最好。本模型没有前导捕获、真实导频估计、FEC、射频损伤或 NTN 链路预算。它与 OFDM 独立星地研究页不是同一模型。

## 页面与任务行为

实时与扫描互斥。开始新任务前验证参数，停止旧任务并确认线程退出；运行中所有实验参数锁定。内部页签切换、返回首页和关闭窗口都会请求停止，保留最后完成的配对结果。若停止超时，保留任务所有权、阻止重启/导航，等待退出后再继续。

扫描结果表中每一行都是完整三波形点，BER 单元格提示包含原始错误/比特、EVM 和区间。JSON 保存当次参数、结果、完成/取消/错误状态及模型假设。停止后修改控件不会重写已保存配置。

## AFDM 参数配置补齐（2026-11-04）

原对比引擎固定 `c1=c2=0.05`，使用 `exp(-j 2π c n²/M)` 的旧归一化口径；独立 AFDM 研究页已经可编辑参数，但对比页没有相应入口。现为实时和扫描分别增加 c1/c2 输入与恢复默认按钮，实际值贯穿模拟器、后台任务、结果摘要和 JSON 快照，运行时锁定。

对比页输入统一采用标准 DAFT 口径 `exp(-j 2π c n²)`，不额外除以 M。默认配置以 `0.05/M` 换算，保留原有发射波形；本页固定 M=64，因此默认 `c1=c2=0.00078125`。公共 API 在未显式指定时按实际 M 换算，避免其他 FFT 配置的默认波形发生变化。手动参数为有限的 `[0, 0.5]` 数值，支持零 chirp 的 OFDM 极限；两个 chirp 只作用于 AFDM 变换。

该改动没有把独立 AFDM 页的训练块或 CPP 插入三波形资源预算，也不要求参数改变后 AFDM 必然优于其他波形。完整理想 CSI 均衡下，chirp 的收益可能很小，应结合实际计数和配置解释结果。

比较范围保持 OFDM / OTFS / AFDM。FDIDM 的重点为软波形参数、特殊参数下的退化关系与自适应过程，在自身页面研究，不并入统一四波形排名。

参数配置新增回归为 `tests/test_compare_chirp_parameters.py`，21 项通过：验证不同 FFT 下默认波形兼容、标准 DAFT 显式变换、零 chirp 极限、只影响 AFDM、实际实时/扫描传参、配置锁定与冻结导出。相关对比回归共 63 项通过，全量结果为 **669 passed**。原生 1100×700、1400×900 检查通过，小窗口无需滚动即可看到 c1/c2；运行按钮保持可见，其余设置可在独立滚动区访问。
