# OFDM 星地链路研究：建模依据、现有缺口与可复现实验

核验日期：2026-11-01。本文区分官方资料中的条件、从离散 OFDM 模型得到的推导、以及平台采用的工程假设。这里的目标是可复现的 SISO 基带链路研究；采用 NTN 时延/功率轮廓，并不等于实现完整 NR NTN 协议或通过射频一致性测试。

## 1. 首先分开三个物理量

| 物理量 | 含义 | 在仿真中的作用 |
| --- | --- | --- |
| 公共轨道多普勒 `f_orbit` | 卫星与终端相对径向运动产生的大频移 | 所有路径共同的相位旋转，可以根据几何/星历预测 |
| 公共残余 CFO `f_res` | 几何预补偿误差、振荡器误差与后续频率跟踪误差 | 接收端前导估计、补偿后仍可能残留，产生 CPE 与 ICI |
| 散射多普勒 `f_D` | 不同散射分量相对公共中心频率的分布 | 决定小尺度时变、导频老化及符号内 ICI |

TR 38.811 §6.9.2 把卫星运动的附加频移施加于所有 TDL 路径，并另外引用 TR 38.901 的各径多普勒谱。其 §5.3.4.3.2 的 600 km 示例给出：2 GHz 最大轨道频移约 ±48 kHz，20 GHz 约 ±480 kHz。这些是指定轨道场景的公共频移示例，不是散射谱宽，也不是任意 LEO 链路的固定参数。§6.8.1 的时变相位需要对瞬时频率积分。[TR 38.811 V15.3.0，ATIS 官方档案，§5.3.4.3.2、§6.8.1、§6.9.2](https://atisorg.s3.amazonaws.com/archive/3gpp-documents/Rel15/ATIS.3GPP.38.811.V1530.pdf)

实际 NTN 不能简单把大公共频移原封不动交给小范围 OFDM 残余频偏估计器。TS 38.300 §16.14.2.2 规定 UE 利用有效 GNSS 位置与星历计算并自主预补偿上行服务链路多普勒；馈电链路与转发器频率误差管理属于网络实现。平台的“几何预补偿”可用于说明这个物理环节，但不应冒充已经实现 GNSS/SIB/星历信令流程。[TS 38.300 V17.12.0，§16.14.2.2，印刷页 179–180](https://www.etsi.org/deliver/etsi_ts/138300_138399/138300/17.12.00_60/ts_138300v171200p.pdf#page=180)

工程模型可显式采用：

```text
f_orbit = (v_radial / c) * f_carrier
f_res = (1 - compensation_ratio) * f_orbit + oscillator_error
phi_res(t) = 2*pi * (f_res*t + 0.5*residual_drift*t*t)
```

这是可解释的误差模型，不是 3GPP 为补偿精度规定的固定百分比。轨道速度不等于径向速度；如果用 `radial_factor`，必须展示这个假设。相干时间也应与所采用的散射谱/相关函数关联，不能用尚未补偿的公共轨道频移直接推断衰落相干时间。

## 2. 可核验的 NTN 时延/功率轮廓

| 轮廓 | 分量时延 ns | 分量平均功率 dB | 衰落组成 |
| --- | --- | --- | --- |
| NTN-TDLA100 | 0 / 110 / 285 | 0 / −4.7 / −6.5 | 三个 Rayleigh tap |
| NTN-TDLC5 | 0 / 0 / 60 | −0.6 / −8.9 / −21.5 | 零时延 LOS 与 Rayleigh 叠加形成 Rician 首 tap，另有延迟 Rayleigh tap |

`100` 和 `5` 表示名义 RMS delay spread，不是最大时延。C5 表中的三个分量对应两个不同的物理时延，不能把三个分量都当成 LOS。可用功率线性值归一化平均 PDP，不能每个实现都把瞬时总接收功率强行变成 1，从而抹去衰落深度。[TS 38.101-5 V18.11.0，Annex B.2.1，表 B.2.1-1/2/3，印刷页 123](https://www.etsi.org/deliver/etsi_ts/138100_138199/13810105/18.11.00_60/ts_13810105v181100p.pdf#page=124)

相同版本 Annex B.2.2 的表 B.2.2-1 列出 `NTN-TDLA100-200`、`NTN-TDLC5-200`、`NTN-TDLC5-1200`；末尾数字是最大多普勒频率 Hz。注意版本边界：V17.10.0 的对应组合表只有两个 200 Hz 条目，不能用该版本证明 1200 Hz 组合。[TS 38.101-5 V18.11.0，B.2.2](https://www.etsi.org/deliver/etsi_ts/138100_138199/13810105/18.11.00_60/ts_13810105v181100p.pdf#page=124)；[V17.10.0，B.2.2，印刷页 53](https://www.etsi.org/deliver/etsi_ts/138100_138199/13810105/17.10.00_60/ts_13810105v171000p.pdf#page=54)

完整 TDL 统计还涉及时间相关性。TR 38.901 §7.7.2 描述各 Rayleigh tap 的经典 Jakes 谱，并对其 LOS 模型加入谱线；其 TDL-D/E 例使用 `0.7*f_D` 的 LOS 谱线。平台若采用有限正弦和、每径单频加 AR 演化或其他近似，应明确近似方式及 LOS 残余频率假设；引用标准 PDP 不能证明这些时间统计自动符合标准。[TR 38.901 V17.1.0，§7.7.2，印刷页 72–73](https://www.etsi.org/deliver/etsi_tr/138900_138999/138901/17.01.00_60/tr_138901v170100p.pdf#page=73)

### 分数时延不可省略

若沿用旧 OFDM `NFFT=64`、`SCS=15 kHz`，则 `Fs=960 kHz`、采样周期约 `1041.67 ns`。直接把 110/285/60 ns 四舍五入成整数采样，所有非零路径都会退化到零时延。提高 FFT 也不能取代分数时延：`NFFT=256`、15 kHz 时，采样周期仍为约 260.42 ns。

可选择带已知群时延的分数延迟 FIR，或者精确频域相位延迟并正确处理线性卷积与跨符号记忆。若直接在各 OFDM 符号上构建循环信道，需要明确已经假设 CP 足够长；这种实现不能用于证明 CP 不足时的 ISI 行为。分数延迟滤波器的群时延应从同步时延中正确扣除，不能当成真实超额路径时延。

## 3. 子载波间隔、频偏、CP 的影响

TS 38.211 §4.2 的通用 numerology 为 `SCS = 15*2^mu kHz`；15/30/60 kHz 均有普通 CP，60 kHz 还支持扩展 CP。具体 NTN 频段、带宽、SCS 的适用组合须查 TS 38.101-5 §5.3.5，而非仅凭通用 numerology。其 V18.11.0 表 5.3.5-1 为部分 FR1 NTN 频段列出 15/30/60 kHz；FR2 NTN 的表 5.3.5-2 列出 60/120 kHz。[TS 38.211 V17.8.0，§4.2、§5.3.1](https://www.etsi.org/deliver/etsi_ts/138200_138299/138211/17.08.00_60/ts_138211v170800p.pdf#page=13)；[TS 38.101-5 V18.11.0，§5.3.5，表 5.3.5-1/2](https://www.etsi.org/deliver/etsi_ts/138100_138199/13810105/18.11.00_60/ts_13810105v181100p.pdf#page=21)

TR 38.821 的链路级研究表 6.1.2-4 使用 S-band 15/30 kHz、Ka-band 60/120 kHz，要求现实信道估计，并给出假定上行预补偿后的 0.1 ppm 残余频率误差研究条件。该值是该研究表的假设，不是所有 NTN 链路的统一残余上限，也不能当作平台仿真的既得补偿性能。[TR 38.821 V16.0.0，§6.1.2，表 6.1.2-4，印刷页 52](https://www.atis.org/wp-content/uploads/3gpp-documents/Rel16/ATIS.3GPP.38.821.V1600.pdf#page=52)

以下数值来自 `T_u=1/SCS` 和普通 CP 短符号公式；实际 NR 还有较长 CP 符号，平台固定 `cp_len` 的小帧不能直接称作完整 NR 时序：

| SCS kHz | 有用符号时长 μs | NR 普通短 CP 约 μs | `200 Hz/SCS` | `1200 Hz/SCS` |
| --- | --- | --- | --- | --- |
| 15 | 66.667 | 4.688 | 0.01333 | 0.08000 |
| 30 | 33.333 | 2.344 | 0.00667 | 0.04000 |
| 60 | 16.667 | 1.172 | 0.00333 | 0.02000 |

对统一残余 CFO，令 `epsilon=f_res/SCS`。从 N 点 DFT 的有限几何级数可得：

```text
|C0| = |sin(pi*epsilon) / (N*sin(pi*epsilon/N))|
P_ici ~= 1 - |C0|^2
SIR_ici ~= |C0|^2 / (1 - |C0|^2)
```

这里的 ICI 功率关系假设满载、等功率、互不相关子载波及常量 CFO；有 DC/保护/导频、时变多径时要计算真实泄漏。`f_D/SCS` 可比较时间选择性，不能直接把散射多普勒宽度当成统一 CFO 套公式。

CP 防御的是正确同步窗口附近的**最大超额多径时延**及剩余定时误差，不是卫星绝对传播时延。CP 也不能修复 CFO 或符号内时变引起的 ICI。增加 SCS 可减小归一化频偏并缩短 CSI 老化时间，同时缩短固定 CP 样本数对应的物理时间；固定 FFT 时，采样率与占用带宽也随 SCS 改变，不能把结果解释为固定带宽下的单因素收益。

## 4. 改造前 OFDM 路径的代码核对

以下是本轮改造开始时对 `simple_ofdm_rx.py`、原 `ofdm_tab.py` 和通用扫描逻辑的检查快照；后续新研究页应据此验证，不能把旧路径的限制误写成新模型的已知行为。

1. **原 OFDM BER 已经来自真实比特比较。** `_step` 生成 `tx_bits`、硬解调 `rx_bits`，统计 `bit_errors/total_bits`；EVM 另由均衡后符号与发送参考符号计算。不能声称旧后端只有 EVM 反推 BER。EVM 低也不能代替 BER、同步成功率与独立样本数量。
2. **失败帧口径需要展示。** 同步失败/同步度量不合格时原实现把该帧所有比特记错。这是失败惩罚口径，不等于已经观测到所有比特翻转。研究模式宜分别提供“有效解调比特 BER”“同步失败帧比例”，或者明确总 BER 所用擦除处理政策。
3. **旧信道不是已核验的 A100/C5。** 固定 15 kHz、64 点 FFT、16 点 CP；用户设置采样数时延，采用简化三径延迟比例、每径频移和帧间 AR 演化；每帧归一化瞬时路径功率。该路径适合兼容波形横向演示，不能直接用作标准 NTN 信道证据。
4. **同步具有已有定时先验。** 原 `_synchronize_and_extract` 只在已知保护长度附近找度量，且实际提取仍使用固定 `frame_start`。应说明这属于已完成粗定时后的残余同步，不能称作全范围星地初始接入。
5. **重复前导的 CFO 范围有限。** 重复距离 `L` 的相位差估计仅在 `±Fs/(2L)` 内无歧义；旧 `L=NFFT` 时是 `±SCS/2`。先做几何补偿，才可以合理使用这个估计器跟踪剩余频偏。
6. **CSI 更新不足。** 原接收机用首训练符号估计一次频率响应，然后七个数据符号保持该响应；四个导频只修正 CPE。它不等于对各子载波持续估计幅度、频率选择性与时间演化。
7. **旧自动扫描不是可审计 BER 研究统计。** 通用扫描按墙钟时长运行、对重复 BER 做对数域合并，默认显示单调包络。研究页应直接累加错误数/比特数，展示原始点和样本规模，不强制单调，不把绘图下限当作实测误码。
8. **随机与噪声口径需要固定。** 原后端默认 `default_rng()` 无显式种子；旧噪声函数按每帧信道输出功率调整噪声，实际近似固定瞬时接收 Eb/N0。若要研究深衰落，噪声应固定参考发射能量/平均链路增益；两种定义都可用，但必须标明区别。

## 5. 建议采用的可复现 SISO 链路契约

这是研究方案，不预设某种策略在每个种子上一定胜出。

- 用固定配置快照定义 `profile / seed / FFT / CP / SCS / modulation / residual_CFO / residual_drift / frame_count`。信道、比特、噪声使用独立可复现随机流，重跑同一快照得到同一原始计数。
- 公共几何频移只用于展示预测值与预补偿残差；基带传播含残余 CFO/漂移及独立散射时变项。对公共频移和各路径时变使用连续采样时间，而非 GUI 刷新墙钟。
- 使用上表 PDP 的物理 ns 延迟与平均功率；SISO 路径功率按平均 PDP 归一化。是否采用 Jakes 近似、LOS 残余频率与有限正弦数都写入元数据。
- 前导提供残余 CFO/定时估计；训练与跟踪导频提供现实 LS/LMMSE 类估计。真实发送比特只用于离线计分，不能反过来为接收机提供数据符号或真信道。
- 以相同发送帧、信道实现、噪声和资源预算并行比较：关闭残余补偿的诊断基线；残余同步加初始训练的基线；导频持续跟踪的改进接收机。真实 CSI 只可作为明确标注的理论参考。
- `Eb/N0` 分母固定为净信息比特；前导、训练、导频、CP 和保护时间的能量开销都计入发送帧能量，并记录这个定义。若采用已知仿真噪声方差给 MMSE，应标为噪声已知的研究假设，不能说已实现盲噪声估计。
- BER 输出 `errors/bits` 原始计数，FER/同步失败单独记录；EVM 是均衡后真实参考辅助 RMS 误差，独立显示。零误码记录 `0/N`，对数图可显示二项独立近似下的一侧 95% 上界 `1 - 0.05^(1/N)`，不能伪装成非零实测 BER。
- 连续衰落下比特错误可能相关；二项/Wilson 区间只能标为近似。严谨结论需多个独立信道种子，必要时按独立块/轨迹做置信区间。
- 若省略编码、HARQ、射频相噪、功放、链路预算、完整 NR DM-RS/资源栅格与协议，则明确这是非编码 SISO 基带研究；不直接套用带编码 NR 的 BLER/吞吐门限。

## 6. 验证矩阵与结果判断

| 实验 | 固定条件 | 改变项与应观察的证据 |
| --- | --- | --- |
| 可复现性 | 完整配置快照 | 重复两次，原始 bits/errors/frame 计数及曲线一致 |
| AWGN 校准 | 平坦静态、理想同步、QPSK | 用相同 Eb 定义校验理论 BER；若计入前导/CP开销，先换算有效数据 Eb/N0 |
| 公共 CFO | 同一静态信道、同一 bits/noise | 扫残余 CFO；记录估计误差、归一化 CFO、补偿前后 BER/EVM |
| 频偏捕获边界 | 固定 SCS、重复距离 L | 跨过 `±Fs/(2L)`，应如实暴露估计歧义或捕获失败，不钳制成好结果 |
| 时变跟踪 | 同一 PDP、200/1200 Hz 轨迹 | 初始训练与持续导频比较；记录估计延迟、净导频开销和 BER/EVM |
| CP 适用域 | 同一物理时延与定时先验 | 扫 CP/时延缩放；CP 不足时的失败需要真正保留线性卷积记忆的信道实现 |
| SCS 研究 | 同一载频、PDP、残余频错模型 | 比较15/30/60 kHz，同时报告带宽、符号时长、CP时长；按频段标注工程/标准配置边界 |
| 统计稳定性 | 固定停止规则 | 每点足够比特/错误数或明确上限；多个独立种子，保存每点原始计数与零误码上界 |
| UI 一致性 | 同一配置快照 | 实时页和扫描页用同一引擎定义；停止/切页不接受旧任务迟到结果，不强制曲线单调 |

性能结论应写成“在指定轮廓、残余频偏、资源/能量预算、帧数与种子集合下，某接收策略降低了实测误码/调制误差”。没有固定能量和资源预算、足够独立样本及原始计数，不能仅凭更圆的星座图或单条平滑曲线宣称星地性能提升。

## 7. 本次实现与已复现的条件性结果

本节依据当前 [研究模型](../waveform_sim/simulation/ofdm_ntn.py)、[复现脚本](../scripts/study_ofdm_ntn.py) 和本机生成的 `output/ofdm-ntn-study.json` 原始结果。运行产物不随源码提交，可用以下命令重新生成：

```powershell
.\.venv\Scripts\python.exe scripts/study_ofdm_ntn.py --frames 40 --seed 42
```

本次实际落地的是标准 NTN 时延/功率轮廓上的**固定种子径幅与初相、每径恒定频率连续旋转的 sum-of-rays 工程模型**。它实现分数时延、线性符号边界及超 CP 路径的跨符号干扰；每个数据符号均有梳状导频，接收端采用导频 LS 频域线性插值和可选 ZF/MMSE。噪声按发射突发能量/净信息比特定义，包含导频与 CP 能量，不随瞬时衰落接收功率重设。

本实现假定辅助帧定时已知，并按配置的公共轨道补偿比例设置残余 CFO；**没有实现前导捕获、盲残余 CFO 估计器或 GNSS/星历协议**。它也没有实现完整 Jakes 统计、FEC、HARQ、射频相噪及链路预算。跨符号 ISI 在单个突发内建模，各突发独立生成；不包含前一突发尾迹对后一突发的跨帧干扰。第 5 节中涉及真实前导估计、额外时间统计校准的内容仍是后续验证/扩展方向，不能算成本次已有功能。

三条曲线的精确定义为：

| 策略 | 实际含义 |
| --- | --- |
| `pilot_ls` | 配置的公共多普勒预补偿 + 各符号导频 LS 插值 + 选定的均衡器 |
| `ideal` | 相同预补偿与波形；用真实信道的主对角项替代导频估计，仅作 CSI 参考；不以先验真值消除全部 ICI/ISI |
| `uncompensated` | 同一发射比特、物理路径及噪声流，将公共轨道预补偿比例设为 0，仍采用导频 LS；它不是关闭全部接收处理 |

默认场景为 C5-200、2 GHz、速度 28080 km/h、径向投影 0.5、99.9% 公共轨道预补偿、128 点 FFT、16 点 CP、30 kHz SCS、QPSK、12 个符号/帧、40 帧/点、seed 42。由该配置计算公共轨道频移约 26018 Hz、补偿后公共残余约 26.018 Hz；采样率 3.84 MHz、CP 时长约 4.167 μs。每点每策略恰好统计 68160 个净信息比特。

### 7.1 能量扫描

### 7.2 附加公共残余 CFO 压力测试

保持 20 dB，扫描值是额外残余 CFO，实际总残余还包含默认约 26.018 Hz：

| 附加残余 CFO | 导频 LS 错误/比特 | 导频 LS BER | 理想对角 CSI BER |
| --- | --- | --- | --- |
| 6000 Hz | 436/68160 | 0.00639671 | 0.00277289 |
| 15000 Hz | 19278/68160 | 0.28283451 | 0.24118251 |

这些结果说明此模型下大残余频错导致的 ICI 不能只靠每符号导频插值与单抽头均衡消除。由于本模型未实现 CFO 捕获估计器，不能把 15 kHz 这个劣化点解释为已经实验验证了某个前导估计器的捕获边界。

### 7.3 时延与 SCS 扫描的解释边界

在 A100 轮廓上施加 `delay_scale=25` 是派生压力场景，不是名义 A100。最大超额时延变成 7.125 μs，超过 4.167 μs CP。20 dB 时导频 LS 得到 `11261/68160 = 0.16521420`，理想对角 CSI 为 `270/68160 = 0.00396127`。CP 不足、频域插值误差、频率选择性、残余时变/ICI 及多径组合共同影响结果；仅凭这两个 BER 数字，不能把全部性能差归因于 CP 不足。分离归因应固定同一物理信道，分别关闭时变/CFO、改变 CP、替换估计器并记录 NMSE。

默认 C5 的 15/30/60 kHz SCS 三点在 20 dB 均观测到 `0/68160`，不能据此给三种 SCS 排性能名次。该扫描固定 FFT 和 CP 样本数：Fs 依次为 1.92/3.84/7.68 MHz，CP 物理时长依次约 8.333/4.167/2.083 μs；带宽、每帧物理时长也改变。因此它是固定 FFT 的联合参数研究，不是等带宽、等观测时间的 numerology 优劣比较。

上述结果仅覆盖 **seed 42 的同一组固定径幅/初相及其连续相位轨迹**，不是多信道实现平均性能。可以据此确认配对比较和异常区间已可复现，后续应增加独立种子、误差预算与统计样本，才能形成更一般的星地链路结论。
