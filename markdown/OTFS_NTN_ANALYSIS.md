# OTFS 星地链路升级与研究口径

更新日期：2026-11-04。

OTFS 仿真页现采用与 OFDM 星地研究相同的场景参数、物理路径和统计定义，并保留原有 Fusion 浅色控件与 MATLAB 配色。实时链路和性能扫描共用一个确定性的数值引擎。本文区分实现内容、接收机假设和可由结果支持的结论。

## 1. 从旧页面升级了什么

旧页采用通用三径链路、采样数时延和固定网格，缺少标准 NTN 时延/功率轮廓、轨道预补偿比例、时延—多普勒分辨率和完整研究快照。实时参数可改变，扫描则另走固定帧数路径；零误码也曾以统计上界替代 BER 数值，容易混淆实测结果与绘图位置。

新版提供：

- S 波段 LOS/NLOS、Ka 波段高动态及 AWGN 预设；与 OFDM 共用 A100/C5 时延功率表和路径实现。
- 分开配置公共轨道频移预补偿、额外残余 CFO 与散射多普勒扩展；保留分数采样时延及单突发内部真实跨符号干扰。
- 可配置延迟维 FFT 点数、Doppler 维时隙数、子载波间隔、每时隙 CP、QPSK/16QAM/64QAM。
- 实时接收频谱、DD 星座、累计 BER 和接收 DD 网格能量；网格能量不是信道估计图。
- 扫描 Eb/N0、额外残余 CFO、散射多普勒、子载波间隔、时延缩放与时隙数；比较训练 LS、理想主对角 CSI、关闭公共预补偿三种条件。
- 原始错误/总比特、FER、EVM、95% Wilson 区间；零误码保留 `0/N`，对数图另画区间上界。导出保存运行时配置，之后修改控件不会改写已有结果。

## 2. 发射机与资源预算

DD 矩阵 `X_dd` 的形状为 `M × N`，M 是延迟维，N 是 Doppler 维。采用单位化 ISFFT：延迟维 FFT、Doppler 维 IFFT；随后对每个 TF 时隙作频率维 IFFT，并加普通 CP。接收侧去 CP、FFT、TF 均衡后，以 SFFT 恢复 DD 符号。矩形脉冲下，这是可由 OFDM 调制实现的 OTFS 结构；本实现没有把 TF QAM 星座改名当成 DD 星座。该变换与脉冲的依据见 [OTFS 教程 Part I](https://arxiv.org/abs/2209.05011) 和 [MathWorks OTFS 调制说明](https://www.mathworks.com/help/comm/ug/otfs-modulation.html)。

每个突发的结构为：前静默保护段、一时隙已知全带宽训练、N 个数据时隙、后静默保护段。训练和每个数据时隙均使用 CP。所有 DD 格点承载载荷；没有嵌入式 DD 导频或数据辅助估计。每个突发的信息比特数为 `M × N × log2(QAM阶数)`。

噪声方差统一使用：

```text
noise_variance = 发射突发实际能量 / (净信息比特数 × 10^(EbN0_dB/10))
```

发射能量包含训练和 CP；静默保护段延长总时长但没有发送能量。衰落后的接收能量不参与噪声重标定。因而深衰落仍造成实际信噪比损失，不会被归一化抹掉。

独立 RNG 流分别生成载荷、物理路径和噪声；种子及帧号决定可复现样本。路径幅度和初相由种子固定，多普勒相位按仿真采样时间连续旋转，不使用 GUI 刷新墙钟。三条策略共用发送比特、路径和单位噪声，不能强制曲线单调或固定排名。

## 3. 接收机的实际含义

| 策略 | 信道信息来源 | 实际处理 |
| --- | --- | --- |
| 训练 LS | 从本突发已知训练时隙的接收 FFT / 已知训练符号获得各子载波 LS 估计 | 训练估计保持至全部 N 个数据时隙；TF 单抽头 ZF/MMSE，再作 SFFT |
| 理想 CSI 参考 | 物理时变信道在各数据时隙的真实 TF 主对角项 | 同样采用 TF 单抽头 ZF/MMSE；不反演整个 ICI/ISI 矩阵 |
| 关闭预补偿 + LS | 公共轨道预补偿比例设为 0，其余处理与训练 LS 相同 | 用于观察公共大频移的影响，并非关闭整个接收机 |

这里的 MMSE 正则项采用已知仿真噪声方差。发送比特和数据符号只用于计算错误及 EVM；没有用于估计信道。当前训练估计不能追踪帧内的相位旋转，因此较长的 N、较大残余 CFO 或更强散射动态可能造成估计老化。理想 CSI 曲线也仍受未消除的 ICI/ISI 影响。

本次没有实现 DD 域消息传递、完整 DD LMMSE、多时刻训练跟踪或盲 CFO 估计器。OTFS 调制本身不会自动消除干扰；参考文献中的 DD 均衡增益不能直接套用到当前 TF 单抽头接收机。页面研究的是所选接收结构的性能与局限，不宣称 OTFS 在所有场景必然优于 OFDM。

## 4. 星地信道与模型边界

NTN 时延/功率数据使用 [ETSI TS 138 101-5 V18.7.0 Annex B.2](https://www.etsi.org/deliver/etsi_TS/138100_138199/13810105/18.07.00_60/ts_13810105v180700p.pdf#page=117) 的 A100/C5 轮廓及 200/1200 Hz 组合，与 OFDM 使用同一张表。其上的散射实现为简化、固定路径幅度的连续 sum-of-rays，尚非完整 Jakes/3GPP 统计信道。

物理波形按线性突发时间线计算。分数路径时延通过源符号的频率相位斜坡求值，并根据实际源符号边界放置；不是把时延四舍五入成采样数，也不会自动补出超出 CP 的循环前缀。超 CP 路径会引入突发内 ISI。不同突发分别生成，不包含前一突发尾迹对后一突发的跨帧干扰。

假设帧定时已知，按配置预先设置公共轨道频移的补偿比例；没有实现定时捕获、GNSS/星历信令、同步失锁统计、FEC/HARQ、功放/相噪或传播链路预算。Ka 预设和非标准缩放属于基带研究参数，不代表 NR 制式一致性配置。

## 5. 如何解释 DD 分辨率与扫描

延迟格点间隔为 `1/(M × Δf)`；Doppler 格点间隔为 `1/(N × T_slot)`，其中 `T_slot = (M + CP)/(M × Δf)` 包含 CP。这里使用普通 CP 每时隙结构，不是整帧只加一个前缀的 reduced-CP OTFS。关系和两种前缀结构的区别见 [MathWorks OTFS 说明](https://www.mathworks.com/help/comm/ug/otfs-modulation.html)。

- 固定 M 改变子载波间隔，会同时改变带宽、CP 时长、DD 分辨率和帧长。
- 改变 N 会同时改变 Doppler 分辨率、训练开销比例、净比特数和训练到最后时隙的时间跨度。较细的 Doppler 格点不保证当前训练保持接收机的 BER 更低。
- 时延缩放不是新的标准剖面。CP 余量为负是 ISI 风险提示；具体 BER 差异还可能含训练误差、频率选择性和 ICI。
- DD 热图画的是接收数据能量，随随机载荷和均衡变化；不能把亮点解释为自动检测到的物理反射路径。

单种子固定路径幅度下的 Wilson 区间是错误计数的条件性近似；相关衰落不等同于独立比特试验，更不代表跨信道的覆盖概率区间。应结合多个独立种子、足够错误数和原始计数做结论。

## 6. 与另外两个页面的关系

OFDM 与 OTFS 星地页对齐的是场景、信道生成、能量定义、统计和操作逻辑。OFDM 采用带保护子载波/DC 的梳状导频，OTFS 采用全 DD 格点加独立训练时隙；资源和信道估计预算不同，两页 BER 不能直接作为同资源波形排名。

“波形对比”页仍使用专门的三波形配对全载波模型，默认理想 CSI 完整 LMMSE；它不是上述训练接收机。涉及三波形性能比较时，应查看该页实际接收机和预算，并参考 [对比页审计](WAVEFORM_COMPARE_AUDIT.md)。

## 8. 本次实际复现的结果

已运行上述命令，完成 32 个扫描点、每点 40 帧、三条策略的实验。原始计数可运行复现命令后在本机生成的 `output/otfs-ntn-study.json` 中查看；运行产物不随源码提交。默认 C5-200、2 GHz、28080 km/h、径向投影 0.5、99.9% 轨道预补偿、M=128、N=12、CP=16、30 kHz、QPSK、seed=42；帧总时长约 0.4958 ms，DD 延迟格点 260.4 ns、Doppler 格点约 2222.2 Hz。训练估计器为帧首 LS，均衡器为 TF 单抽头 MMSE。

| 扫描条件 | 训练 LS 错误/比特 | 训练 LS BER | 理想对角 CSI BER |
| --- | --- | --- | --- |
| Eb/N0=12 dB | 929/122880 | 0.0075602 | 0.00076497 |
| Eb/N0=20 dB | 0/122880 | 0 | 0 |
| 20 dB，额外残余 CFO=300 Hz | 5984/122880 | 0.0486979 | 0 |
| 20 dB，额外残余 CFO=1500 Hz | 73043/122880 | 0.5944255 | 0 |
| 20 dB，散射扩展=1200 Hz | 1486/122880 | 0.0120931 | 0 |
| 20 dB，N=48，其余默认 | 4007/491520 | 0.0081523 | 0 |

20 dB 默认条件下的零误码有双侧 95% Wilson 上限约 `3.1261e-5`，不能解释成真实链路 BER 保证为零。关闭轨道预补偿时得到 `61189/122880 = 0.49796`。

额外 CFO=1500 Hz 的训练 LS BER 超过 0.5 并不被截断：固定比特映射在持续相位旋转、错误象限判决下，有限样本 BER 可以超过 0.5。此处估计仅在帧首测量，后续公共相位旋转没有跟踪；这是接收机老化的表现，不能解释成 OTFS 变换损坏。理想对角 CSI 的零误码则受先验优势与样本量限制，也不能证明没有 ICI。

N 从 12 增至 48，Doppler 格点间隔从约 2222.2 Hz 降为 555.6 Hz，而总帧长从约 0.496 ms 增至 1.846 ms。当前保持训练估计的接收机反而劣化，说明研究需要同时评估帧长、训练跟踪和开销，不能只看网格分辨率。

A100 时延缩放 25 倍时最大超额时延为 7.125 μs，超过默认 CP 4.167 μs；实测 LS 为 `1537/122880`，理想对角 CSI 为 `659/122880`。这同时包含估计误差、时变和 ISI；精确归因应分别控制时变、CP 与估计方式。以上结果只针对这一固定幅度路径实现，不构成跨波形或跨衰落集合的性能优劣结论。
