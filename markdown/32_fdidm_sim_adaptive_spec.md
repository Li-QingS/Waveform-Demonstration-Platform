# FDIDM 仿真侧自适应 Spec

> 本文档为软波谱 Spec 驱动开发流程的阶段一产物，未获用户批准前不进入 plan/task 阶段。

## 背景

- 当前 FDIDM 软件仿真后端 `waveform_sim/simulation/simple_fdidm_rx.py` 只有一次性理论搜索 `search_best_indices`：搜索完给出一个最优 (α, β) 就结束，没有“运行过程中持续跟随信道变化、自动调整参数”的能力。
- 硬件端 FDIDM 已有一套成熟的预测式自适应机制（按帧取 CSI 快照 → 论文 SER 理论搜索 → 稳定性判定 → 冷却 → 自动应用），仿真侧缺的是同等能力。
- 框架入口已预留：`AdaptiveConfig`（`waveform_sim/core/config.py`）与 `LinkSimulator.start_adaptive_tuning`（`waveform_sim/core/engine.py`）均已存在，但仿真后端没有真正接上。
- 目标场景：LEO 时变信道 / 动态信道 / 不同 SNR 下，FDIDM 仿真的 α/β 自动跟随调整，并在 UI 上完整看到“参数怎么变、为什么变”。

## 目标

- G1：在 FDIDM 软件仿真中实现可启停的预测式自适应闭环，行为与硬件端机制一致（CSI 快照 → 理论 SER 搜索 → 稳定判定 → 冷却 → 自动应用）。
- G2：在 FDIDM 仿真页新增“自适应过程”完整分析视图：α(t)/β(t) 轨迹曲线、预测 SER 对比曲线（当前 vs 推荐）、切换标记、状态文本。
- G3：自适应逻辑收敛在仿真后端，UI 只透传配置并展示；对外能力风格与硬件端对齐，便于后续其他波形复用。

## 功能需求

- F1：预测式自适应闭环。FDIDM 仿真运行时，后端按可配置的评估间隔（帧数）取最新 CSI（H_TF 快照），对候选 (α, β) 网格用论文 ZF/MMSE 理论 SER 评估（粗搜 + 细搜，受 M×N 上限约束），输出推荐值、预测 SER（当前 / 推荐 / OFDM 参考）与预测增益 dB。
- F2：决策与切换策略。连续 stability_evals 次推荐一致（容差内）才允许应用；预测增益低于 min_improvement_db 不切换；应用后进入 cooldown_frames 冷却期防抖；数值平局时保持当前参数不动；提供“自动应用”开关，关闭时只出推荐不改变参数。
- F3：生命周期与控制接口。后端暴露启动 / 停止 / 立即评估 / 状态查询 / 历史查询等能力（与硬件端接口风格对齐：start / stop / 立即评估 / get_adaptive_status / get_adaptive_history）；粗细步长、评估间隔、稳定次数、最小增益、冷却帧、上限阶数、自动应用开关等参数可运行时更新；调制阶数、网格形状、均衡器、信道模型等非 α/β 上下文变化时，旧推荐作废重新评估（与硬件端 context 失效一致）。
- F4：历史记录。后端在内存中记录评估事件（帧号、当前/推荐 α/β、预测 SER、增益、动作 skip/apply/cooldown）与切换事件（帧号、旧值→新值、增益），设容量上限，供 UI 绘图与状态查询。
- F5：可视化与操作（FDIDM 仿真页新增“自适应过程”面板）：
  - α(t)、β(t) 两条轨迹曲线，随帧滚动更新；
  - 预测 SER 对比曲线（当前参数 vs 推荐参数，log 纵轴）；
  - 轨迹上标记实际应用切换的帧点；
  - 状态文本：当前/推荐 α/β、预测增益 dB、稳定计数、状态（等待 / 搜索中 / 冷却 / 已应用 / 错误）、上次搜索耗时与候选数；
  - 控制区：启用开关、自动应用开关、参数编辑、立即评估按钮（逻辑仍在后端，UI 只透传配置并展示）。

## 非功能需求

- N1：不阻塞。自适应搜索在后台线程运行，不阻塞仿真主循环与 UI 刷新；单次搜索耗时受 M×N 上限和步长约束，控制在可接受范围（与硬件端同量级）。
- N2：兼容性。不启用自适应时，FDIDM 仿真行为与现状完全一致；现有 `search_best_indices` 等接口行为不变；全部现有测试保持通过。
- N3：一致性。状态与历史字段的命名风格与硬件端 `fdidm_adaptive.py` 对齐，便于后续统一和复用。
- N4：线程安全。自适应线程与仿真收发机共享状态时加锁保护，无数据竞争；UI 通过现有定时器机制轮询，与仿真更新频率解耦。
- N5：可维护性。自适应逻辑集中在仿真后端，UI 只透传配置与展示；新增逻辑配套单元测试。
- N6：资源占用。历史记录设容量上限，不随运行无限增长。

## 不做的事

- 其他波形（OFDM / OTFS / AFDM）的自适应。
- 链路级自适应（调制阶数、编码率、发射功率）。
- 反馈式自适应（实测 BER/EVM）及其与预测式的效果对比。
- `compare_scan_backend` 的“各波形自适应后公平对比”模式。
- 硬件侧的任何改动（`fdidm_adaptive.py` 及其 UI 不动）。
- 硬件端“实测性能面”（α/β 实测 EVM 面）这类扩展展示，不移植。
- 自适应历史/推荐的持久化、导出或接入实验记录服务。
- 除本 spec 描述外的其他可视化形态（如热力图、3D 曲面）。

## 验收标准

- AC1：动态信道场景下启用自适应运行若干帧，历史中出现至少一次 apply 切换（静态 / 无变化信道下保持零切换或平局不切换），α/β 轨迹曲线随帧更新。
- AC2：每次评估事件包含帧号、当前/推荐 α/β、预测 SER（当前 / 推荐 / OFDM 参考）、增益 dB、动作类型、候选数与搜索耗时。
- AC3：仅当连续 stability_evals 次推荐一致且增益 ≥ min_improvement_db 时才 apply，否则动作记为 skip；apply 后冷却期内不再出现第二次 apply（帧间隔 ≥ cooldown_frames）；自动应用关闭时参数不变、推荐仍可见。
- AC4：启动 / 停止可重复调用；“立即评估”立刻产出一轮评估；调制阶数、网格形状、均衡器、信道模型等上下文变化后旧推荐作废、状态回到等待。
- AC5：历史记录不超过配置容量上限；切换事件包含旧值→新值、增益、触发帧号。
- AC6：可视化面板同时呈现 α/β 轨迹、预测 SER 对比、切换标记、状态文本四类元素并实时刷新；启用 / 自动应用 / 参数控件即时生效。
- AC7：自适应搜索运行期间，仿真帧计数持续增长、UI 可正常操作，无阻塞卡顿。
- AC8：不启用自适应时仿真行为与现状一致；`python -m pytest -q` 全部通过（含新增测试）。
- AC9：新增单元测试覆盖搜索内核、稳定/增益/冷却决策、历史记录与并发安全。
