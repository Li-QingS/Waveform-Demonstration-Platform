# FDIDM 接收机相关 GMI 自适应 Spec

## 背景

现有 FDIDM 硬件平台根据实测信道矩阵和噪声方差，在连续的 α/β 参数平面上预测有限星座 SER，并通过真链路顺序窗口验证候选。该机制能够寻找局部候选，但仍存在三个工程与理论问题：

- 自适应目标没有显式表示接收机丢弃的信道耦合分量，难以解释为什么某些接收机需要 α/β 自适应、而完整接收机不需要；
- 连续粗细网格搜索没有固定库容量、公共控制开销和波形 token 概念，无法按照共同资源预算公平比较固定波形与自适应波形；
- 预测 SER、硬件 EVM、CRC 和切换判据混在同一闭环内，接收机重收敛或信道漂移可能被误判为波形收益。

本功能依据《Receiver-Dependent GMI Geometry for Finite Transceiver Libraries》，在固定接收机和公共物理资源预算下建立有限 FDIDM 波形库，以接收机相关 GMI 作为选择目标，并保留真链路指标作为独立验证证据。

## 目标

- 建立可复现、可测试的接收机相关 GMI 计算与有限波形库基线。
- 将在线自适应从连续 α/β 搜索改为有限 token 库中的鲁棒选择。
- 在同一导频、保护、控制字段、发送功率和接收机规则下，公平比较固定波形与有限库自适应。
- 明确展示对角接收机中的 FDIDM 自适应收益，以及完整匹配接收机中的 α/β 不敏感性。
- 将理论选择指标与硬件健康/效果指标分离，使切换原因和验证结果都可解释、可导出、可回溯。

## 功能需求

- F1：系统必须能够根据固定输入功率、噪声协方差、有效信道和指定接收机投影，计算每个 α/β token 的每个有效物理样本 GMI；对角接收机必须支持论文给出的公共指数区间，完整匹配接收机必须提供动作不敏感的参考结果。
- F2：系统必须固定最大库容量 \(\bar M\)，并使库内所有规模共享由 \(\bar M\) 决定的控制字段、训练、保护、采样、带宽、能量和接收机配置。首期默认 \(\bar M=16\)。
- F3：系统必须在 α、β 的周期等价类上构造有限波形库；对角接收机首期使用不重复的半开基本域 \([0,2)\times[0,2)\)，不得同时保存 GMI 等价的周期端点。
- F4：离线库构造必须支持接收机相关的非均匀方向分辨率，能够利用局部 GMI 曲率或经验证的等价代理为 α、β 分配不同数量的候选点。
- F5：离线库构造必须支持固定规模的最坏情形损失最小化，并至少提供一种基于有限状态/候选集合的覆盖式选择方法；输出不得超过库容量上限。
- F6：每个可执行 token 必须记录完整实验上下文，包括 α/β、接收机模式、估计与均衡规则、训练/保护结构、功率约束、控制预算、数值实现版本和实现误差信息；只记录 α/β 的条目不得作为可执行库项。
- F7：在线选择只能使用当前可获得的信道、噪声、同步和实现状态，不得使用已知 payload 符号或解码答案参与候选排序。
- F8：在线选择必须在估计 GMI 上扣除状态不确定性、实现误差和切换成本；只有候选相对当前 token 的保守改善超过门限时才允许发起切换，否则保持当前 token。
- F9：GMI 是自适应选择的主指标；数据辅助 EVM、SER、BER、CRC、同步质量和 overflow 是切换后的独立验证指标。平台不得把 EVM 改善直接标注为 GMI 改善。
- F10：候选切换后的真链路验证必须使用相同功率合同和公共物理资源，在同步、CFO、导频拟合、接收功率及采样连续性稳定后才采集证据；验证顺序必须抵消时间漂移，首期采用等样本 ABBA 设计。
- F11：当验证出现 overflow、采样间隙、功率不一致、收敛指纹不稳定或收益证据不足时，结果必须是“不确定/回滚”，不得提交候选或输出优势结论。
- F12：硬件页面必须用有限数量的工程选项控制自适应，首期暴露接收机模式、库预算和鲁棒等级；连续搜索的粗步长、细步长、稳定次数等算法参数不得出现在默认操作区。
- F13：优势观测区域必须显示当前接收机模式、库 token 编号、当前/候选净 GMI、GMI regret、置信状态和验证结论，同时保留 EVM、CRC、overflow 等硬件证据。
- F14：系统必须保留固定波形 \(M=1\) 和完整匹配接收机两类对照实验，并确保它们与自适应实验采用相同的最大库控制预算和公共资源定义。
- F15：现有 SER 预测可保留为诊断信息或兼容路径，但不得在 GMI 模式中绕过 GMI 判据自动提交候选。

## 非功能需求

- N1：GMI 与有限库核心计算必须与 Qt、GNU Radio 和 UHD 解耦，可在没有射频硬件的测试环境中确定性运行。
- N2：相同状态集、候选集、库预算和随机种子必须产生相同的库及选择结果，并记录足以复现实验的配置摘要。
- N3：所有公开的 GMI、regret、置信界和惩罚项必须为有限数或明确标记为不可用，不得把 NaN/Inf 伪装成有效增益。
- N4：在线评分不得阻塞接收监测线程；默认 16×16 波形、16 个 token 的一次对角接收机评分应在一个正常处理周期内完成。
- N5：GMI 模式必须兼容现有硬件启动、停止、状态查询、日志导出和回滚安全机制；关闭 GMI 自适应时，固定 α/β 硬件链路行为保持不变。
- N6：所有自动化测试不得发射射频；真机验收必须使用显式、受限的 TX/RX 增益和可终止的短时运行流程。
- N7：理论 GMI、有限星座/BICM 指标和实测链路指标必须在命名和页面文案中明确区分。
- N8：库文件或导出证据必须包含格式版本，未知版本必须拒绝执行而不是静默降级。

## 不做的事

- 首期不证明任意非交换、任意硬件失真信道满足论文的解析曲率定理；解析曲率只作为候选布局与筛选依据，最终结论由离散 GMI 计算和验证数据给出。
- 首期不实现新的信道编码、译码器或 HARQ，也不以 GMI 取代现有 CRC/FEC 功能。
- 首期不承诺完整实现所有循环带宽 \(K\) 的高阶通用矩阵 GMI 在线优化；必须实现对角接收机主路径和完整匹配接收机对照，并为后续带状接收机保留明确扩展边界。
- 首期不允许自适应自动改变射频增益、载频、采样率、调制阶数或编码方式。
- 首期不把论文的 Gaussian-input GMI 直接表述为实际有限星座编码吞吐率；有限星座/BICM-GMI 属于独立工程指标。
- 首期不使用 payload 真值训练或选择波形；payload 真值只可用于切换后的实验验证。

## 验收标准

- AC1：论文第 VI 节的 2×2、对角接收机数值例子能够由独立测试复现，包括两组 SNR 下的局部曲率方向关系、非均匀 α/β 分配方向以及有限库相对等数量网格的改进趋势。
- AC2：对角接收机测试验证 α 或 β 平移 2 后 GMI 保持一致，基本域中不存在周期端点重复 token。
- AC3：完整匹配接收机测试验证同一信道的不同 α/β token 在数值容差内具有相同 GMI，并在页面上显示为“无需基于 GMI 切换”的对照状态。
- AC4：构造任意 \(M\le\bar M\) 的库时，token 数量不超过上限，所有 token 的公共训练、保护、控制字段、功率和接收机资源摘要一致。
- AC5：在固定状态/候选测试集上，接收机相关非均匀库的最大 GMI regret 不高于同规模等数量网格；无法改善时必须给出可解释结果而非伪造收益。
- AC6：在线选择测试表明：候选净 GMI 改善下界未超过门限时保持当前 token；超过门限时只产生一个可追踪的候选切换请求。
- AC7：在线候选排序在移除 payload 真值后结果不变；任何 payload 真值输入都不会进入选择器接口。
- AC8：ABBA 验证测试表明线性时间漂移不会被误判为候选收益；overflow、采样间隙、功率失配或稳定性不足均导致不确定并安全回滚。
- AC9：默认硬件页面无需展开高级区即可看懂“当前接收机—库 token—GMI 选择原因—真链路验证结果”，且四个观测区域在项目支持的最小窗口下不发生挤压变形。
- AC10：固定波形、GMI 自适应和完整接收机对照的导出记录包含相同公共资源预算、理论指标与硬件指标的明确分组。
- AC11：关闭 GMI 自适应后，现有固定 α/β 解调、状态显示和停止清理测试全部通过；项目完整自动化测试无回归。
- AC12：真机短测中没有遗留运行流图，验证窗口没有 overflow/采样间隙，且每次提交或回滚都能由日志中的 token、功率合同、GMI 判据和验证证据重放原因。
