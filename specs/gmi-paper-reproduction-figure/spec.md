# GMI 论文复现结果图 Spec

## 背景

现有论文复现命令能够计算并输出曲率、有限库方向分配、sampled regret 和相对改善，但只提供终端 JSON，不便于人工验收和汇报。需要在不改变论文计算口径的前提下，为同一条命令增加可直接查看的静态结果图。

## 目标

- 运行论文复现命令后默认生成一张 PNG，不弹出交互窗口。
- 图片能够直观解释为什么接收机相关的 4×9 非均匀库优于同预算的 6×6 等数量网格。
- 保留现有 JSON 终端输出和可选 JSON 文件输出，保证旧验收流程兼容。

## 功能需求

- F1：默认运行命令时生成 PNG，并在终端明确打印图片保存位置。
- F2：图片同时展示 `rho=1` 和 `rho=10` 两个论文场景的 α/β 曲率或敏感方向。
- F3：图片展示容量 36 下的 4×9 接收机相关分配与 6×6 等数量分配，能够直接比较两个方向的采样密度。
- F4：图片展示两种分配的 sampled regret，并标注相对改善百分比。
- F5：调用者可以指定 PNG 保存位置；父目录不存在时应自动创建。
- F6：调用者可以显式关闭图片生成，以支持只需要数值结果的自动化调用。
- F7：现有数值结果、字段名称、排序和可选 JSON 输出保持不变。

## 非功能需求

- N1：无显示器、远程终端或 CI 环境也能生成图片，不依赖交互式窗口。
- N2：相同参数重复运行应产生相同的数值和视觉内容。
- N3：图片中的标题、图例、坐标和关键数值在常见 1080p 显示器上清晰可读。
- N4：绘图失败时命令应明确报错，不得生成看似成功但内容不完整的图片。

## 不做的事

- 不提供交互式缩放、悬停或弹窗。
- 不修改 GMI、曲率、方向分配或 regret 的数学实现。
- 不接入主程序 UI，也不依赖 USRP 硬件。
- 不在本轮生成 PDF、SVG、动画或三维图。

## 验收标准

- AC1：直接运行论文复现命令后，终端仍输出原 JSON，并生成一张有效 PNG。
- AC2：PNG 中可读出两个 `rho` 场景、4×9 与 6×6 分配、两组 regret 及 13.0%/15.4% 改善。
- AC3：指定自定义路径时文件写入该位置，使用关闭开关时不生成图片。
- AC4：在无图形显示环境下运行成功，且不会等待用户关闭窗口。
- AC5：加入自动测试，验证图片存在、PNG 文件头正确、尺寸合理，同时原论文数值回归继续通过。
