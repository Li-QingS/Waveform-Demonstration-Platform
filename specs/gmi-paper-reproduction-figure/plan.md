# GMI 论文复现结果图 Plan

## 架构概览

保留现有论文数值复现函数作为唯一数据源，在命令行适配层增加静态绘图器。绘图器只消费已生成的结果字典，不重新计算或修改 GMI 数值；命令完成数值输出后，以无界面渲染后端生成 PNG。

## 核心接口

### `render_paper_figure(report, output_path)`

- 输入：论文复现结果字典、目标 PNG 路径。
- 行为：校验两个论文场景和绘图字段，创建父目录，渲染并原子式写出 PNG。
- 输出：解析后的绝对文件路径。
- 失败：字段缺失、数值无效或图片无法写入时抛出明确异常，命令返回非零状态。

### 命令行参数

- `--figure PATH`：指定 PNG 路径，默认写入项目的 `artifacts/gmi_paper_example.png`。
- `--no-figure`：关闭图片生成；与 `--figure` 同时使用时明确报配置错误。
- 现有 `--evaluation-points` 与 `--json` 行为保持不变。

## 模块设计

### 数值复现层

**职责：** 继续生成曲率、方向分配、regret 和改善比例。

**变更：** 无数学变更，绘图器直接使用返回值。

### 静态绘图层

**职责：** 使用 Matplotlib 的非交互 `Agg` 后端生成固定尺寸 PNG。

图片布局：

1. α/β 曲率对比：按 `rho=1/10` 分组的双柱图。
2. 等数量库：6×6 周期基本域散点网格。
3. 接收机相关库：4×9 周期基本域散点网格，并突出 β 方向更密。
4. regret 对比：两个 `rho` 下 equal/receiver-dependent 的分组柱图，直接标注 13.0%/15.4% 改善。
5. 页眉/页脚：公共预算、评估网格、频谱和保存元数据。

所有文字使用英文和数学符号，避免不同 Windows 中文字体造成缺字；关键数值使用稳定格式。

### 命令行适配层

**职责：** 解析路径/关闭开关、打印原 JSON、生成图片并打印绝对保存路径。脚本不调用 `show()`，因此不会弹窗或阻塞。

## 技术决策

| 决策点 | 选择 | 理由 |
|---|---|---|
| 绘图库 | Matplotlib，并声明为项目依赖 | 静态科研图成熟，当前虚拟环境已有 3.8.1，布局和无界面导出稳定 |
| 渲染后端 | `Agg` | 不需要显示器、Qt 事件循环或交互窗口 |
| 默认行为 | 生成固定路径 PNG | 用户执行原命令即可得到图，不增加必填参数 |
| 数值来源 | 只消费现有 report | 避免绘图代码和论文计算形成两套口径 |
| 输出安全 | 临时文件完成后替换目标 | 避免绘图失败时留下半张或损坏图片 |
| 图片测试 | 文件头、像素尺寸、非空像素及 CLI 行为 | 同时覆盖“生成了文件”和“不是空白占位图” |

## Spec 覆盖

- F1/F5/F6：由 CLI 默认路径、自定义路径和关闭开关覆盖。
- F2/F3/F4：由四类面板覆盖。
- F7：数值层不改动，并保留既有回归测试。
- N1：`Agg` 后端覆盖。
- N2/N3：固定布局、尺寸、颜色与格式覆盖。
- N4：字段校验、原子输出和失败测试覆盖。
