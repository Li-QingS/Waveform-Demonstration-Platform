# FDIDM 硬件优势观测升级 Spec

## 背景

FDIDM 硬件页目前具备频谱、星座、EVM、α/β 性能面等诊断能力和一条"自适应效果观测"细栏（开启前/开启后/变化三个文本标签），但评审难以从中读出"软波形自适应比固定参数好"的可信结论。问题有两层：

1. **测量方法层**：开启自适应前后的实测窗口没有配对机制，overflow/失步等链路异常窗口照常混入统计，样本数不透明——已知历史教训是"预测 SER 有增益、实测无改善"（fdidm-hardware-stability）和"RX overflow 波动远大于 α/β 优化收益"（UPGRADE_PLAN 问题4/5），改善量经常淹没在波动里且无法自证可信。
2. **展示形式层**：优势信息只有三个小数字，没有把"信道变化 → α/β 跟随 → 性能恢复"的因果过程可视化，评审看不到软波形的核心价值。

演示条件已确认：单台 USRP + TDL→RF 时变信道注入，受众为通信专家评审，对比机制为**评审手动开关自适应 + 页面自动配对统计**。本功能在现有 FDIDM 硬件页内升级，不做自动定时 A/B 交替。

## 目标

- 评审手动开关自适应时，页面自动完成前后窗口的配对统计，实时给出带证据等级和样本数的改善量，不伪造结论。
- "信道变化 → α/β 跟随 → 性能恢复"的因果过程在一张时间轴图上可读。
- 异常链路数据（overflow/失步/样本不足）自动剔除并明示，统计门槛照标准、不自创。
- 清理已废弃的定时对比残留代码，避免两套对比词汇共存。
- 观测会话可导出留档，供评审带走证据。

## 功能需求

- F1: 页面提供"开始观测 / 结束观测"控制。开始后记录整个观测会话：评审每次手动开关自适应的时刻自动标记为事件；再次开始清空旧观测结果；结束后结果保留可查看。
- F2: 实测指标按时间窗口滚动汇总。开关事件发生时，以事件为界把"关闭期窗口"与"开启期窗口"配对，输出开启前/开启后/变化三组数字。每个窗口记录其信道统计上下文（TDL 注入参数、样本量、异常状态）；上下文明显不可比的窗口对要标注"可比性受限"，不得冒充严格配对。
- F3: 每个汇总数字附带样本帧数、错误计数与可信度分级——错误数 ≥100 为"可信"，10–99 为"参考"（灰显），<10 为"样本不足"（不进结论）。overflow/失步等链路异常窗口自动剔除，并显示剔除窗口数。
- F4: 一张滚动时间图叠加呈现——信道质量代理量（估计 SNR 或 EVM）、实测 SER（对数轴）、α/β 取值轨迹、自适应开关事件竖线、参数应用事件标记、异常剔除区间阴影。评审能沿时间轴直接读出"信道变 → α/β 动 → SER 降"。
- F5: 页面显著位置呈现当前结论：固定参数期 vs 自适应期的实测 SER / EVM 汇总值、改善量（dB）、样本数与可信度徽标。结论措辞严格区分实测与预测——模型预测 SER 只作"预期"参照，永不进入"实测改善"结论。
- F6: 观测面板内可见当前 α/β、自适应搜索状态（含轴可观测性提示）与最近一次参数应用/回滚原因，与现有自适应控件不冲突。
- F7: 移除已隐藏的"单 USRP 优势对比"定时交替控件及其后端逻辑，全仓无残留引用。
- F8: 观测会话（窗口统计、事件序列、结论、异常剔除记录）可一键导出为文件，走现有日志导出路径。

## 非功能需求

- N1: 单台 USRP，不新增第二台设备、第二套 flowgraph 或并行射频链路。
- N2: 窗口统计与结论计算不阻塞 Qt 主线程，走现有后台刷新机制。
- N3: 不改变射频安全限制、功率归一化与 TDL 注入引擎本身；手动开关自适应沿用现有 live update 路径，观测功能不得引入 UHD 重启。
- N4: 无硬件时可离线测试：配对、分级、汇总逻辑可离屏单元验证；测试不依赖 USRP / GNU Radio / 显示器。
- N5: 实测与预测指标严格分开标注；预测值永不进入结论。
- N6: 统计门槛不自创，全部照标准（MATLAB ≥100 错误建议等）。

## 不做的事

- 不做自动定时 A/B 交替对比（评审机制已选定手动开关；旧定时对比代码清理但不复活）。
- 不恢复通用多波形硬件页，不做 OFDM/OTFS/AFDM 硬件基线。
- 不新增页签（现有 FDIDM 硬件页内升级）。
- 不声称严格同时刻逐样本配对——时变信道下前后窗口是统计可比而非逐样本可比，措辞按此约束。
- 不做自动增益控制、信道预测、机器学习。
- 不修改接收算法行为（本周期只加观测与统计，不动接收机）。

## 验收标准

- AC1: 离屏测试能创建观测面板并初始化为空；给定模拟窗口序列能算出开启前/开启后/变化及样本数；再次开始观测会清空旧结果。
- AC2: 模拟后端演示中，配对窗口来自开关事件两侧的正确时间区间；含 overflow 的窗口被剔除并显示剔除数。
- AC3: 错误数 <10 的窗口显示"样本不足"且不进结论；≥100 错误的结论带可信徽标；10–99 灰显为参考。
- AC4: 时间轴图包含信道代理量、实测 SER、α/β 轨迹三条可区分曲线，以及开关事件竖线与剔除区间阴影；观测面板可见当前 α/β 与自适应搜索状态。
- AC5: 结论面板的改善量与窗口统计一致；预测值（若有）明确标"预测"，不与实测混合。
- AC6: 开关自适应走 live 路径，模拟后端能证明未因观测功能调用 stop/start。
- AC7: 废弃定时对比控件与后端逻辑已删除，全仓无残留引用；现有测试与导入测试全部通过。
- AC8: 观测会话可导出为文件，内容含窗口统计、事件序列与异常剔除记录。

## 方向修订（2026-09-07）

初版 spec 经分段审批通过。与 2026-09-03 修订的关系：本版本继承"手动开关自适应"的评审机制，但将其从"三个文本标签"升级为"自动配对统计 + 因果时间轴 + 证据分级"的完整观测面板，并把废弃定时对比的残留代码彻底清理（F7）。
