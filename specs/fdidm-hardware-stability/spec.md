# FDIDM 硬件链路稳定性与自适应闭环 Spec

## 背景

最新真实链路日志出现 RX 数据大块跳变并伴随 overflow；自适应日志里的 SER gain 是模型预测值，应用后 EVM/BER 没有稳定改善。必须先保证接收观测可靠，再用真实接收帧验证候选 α/β。

## 目标

- 识别并抑制异常 RX 积压，提供可观测的 overflow 统计。
- 将自适应改为“候选参数 → 应用/同步等待 → 实测验证 → 接受或回滚”。
- 明确区分预测改善与实测改善，链路不稳定时不下结论。

## 功能需求

- F1: 状态接口提供 RX 异常次数、最近异常样本量和异常原因。
- F2: monitor 检测异常大的 RX 增量时跳过该窗口解码/CSI 更新，推进游标并继续消费。
- F3: 推荐参数应用后进入 validating，不得直接显示为已生效收益。
- F4: validating 丢弃切换瞬态，等待连续有效帧后统计真实 CRC、SER、FEC BER、EVM。
- F5: 验证恶化、失步或超时则自动回滚旧 α/β，并记录原因。
- F6: 页面/日志分别展示 predicted_improvement_db 与 measured_improvement。
- F7: 保留现有频谱、星座、EVM 和 α/β 性能面诊断能力。

## 非功能需求

- N1: 不增加第二台 USRP 或并行射频链路。
- N2: overflow 检测、自适应搜索和验证不得阻塞 Qt UI 或 UHD 消费路径。
- N3: 不把预测 SER 当作真实链路结论。

## 不做的事情

- 不恢复单 USRP 的定时 baseline/adaptive 严格对比实验。
- 不在 overflow 未解决时扩大搜索范围制造收益。

## 验收标准

- AC1: 离屏测试构造异常 RX 增量时，异常计数递增，窗口跳过且线程继续运行。
- AC2: 候选应用进入 validating；真实指标满足门槛进入 accepted，否则回滚并进入 rollback。
- AC3: 状态同时提供预测与实测字段，预测值不会触发绿色改善结论。
- AC4: 异常 RX 窗口不会触发高成本解码、CSI 更新或自适应推荐。
- AC5: 现有硬件导入测试和项目原有测试保持通过。
