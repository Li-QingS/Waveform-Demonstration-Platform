# FDIDM 硬件观测效果可视化 Spec

## 背景

硬件观测页目前把 SER、EVM、α/β 三条时间轴并列展示，用户看不到“自适应前后”的直接差异。逐帧值还会受短窗口、同步重锁和异常帧影响而剧烈跳变，导致页面像调试日志而不是效果证明。

## 目标

- 首屏第一张图直接回答“自适应前后是否改善”，同时显示基线与候选窗口的 EVM、SER 和改善百分比。
- 第二张图展示链路质量随时间变化，并区分稳定段与异常段。
- 第三张图展示 α/β 参数动作与应用时刻，建立“参数变化 → 性能变化”的因果关系。
- 文本框只给出一句话结论和三项证据，专业字段收进可展开详情/tooltip。

## 功能需求

- F1：第一张“自适应效果”图以基线/候选两组窗口为主，分别显示 EVM(%)、SER(%)、有效帧数和改善量；改善为正显示绿色，退化显示红色，证据不足显示灰色。
- F2：第二张“链路质量趋势”图显示稳健 EVM 趋势和 SER 趋势（双轴或可切换指标），异常帧以断点/阴影表示，不把异常平滑成正常值。
- F3：第三张“自适应动作”图显示 α、β 阶梯轨迹、候选应用/回滚标记及时间轴状态，图例直接解释每个动作。
- F4：文本框首行显示 `FDIDM 自适应：改善/无结论/已回滚`，随后显示 `基线 → 候选`、改善百分比和有效帧数；SER/EVM 定义和功率合同放入 tooltip。
- F5：三张图共享时间轴，开关、应用、回滚和异常阴影在同一时刻对齐。

## 非功能需求

- 不改变后端解调、同步、自适应和证据判定逻辑。
- 保持现有 2×2 布局、导出字段和旧日志兼容。
- 离屏环境可运行，新增 UI 逻辑可单元测试。

## 验收标准

- AC1：用户无需阅读日志即可在第一张图看到基线/候选 EVM、SER 和改善量以及颜色化结论。
- AC2：三张图共享时间轴并能对齐参数应用与性能变化；异常段不形成伪造断崖。
- AC3：文本框首行可独立表达改善、无结论或回滚，且包含有效帧数证据。
- AC4：现有 FDIDM 专项测试全部通过，并新增观测显示回归测试。
