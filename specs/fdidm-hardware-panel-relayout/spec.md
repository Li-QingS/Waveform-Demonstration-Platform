# FDIDM 硬件页面板重排 Spec（2026-09-07）

## 背景
右栏四层竖向堆叠（结论组 / 2×2 图阵 / 时间轴 / 文本区）互相挤压：诊断图仅约 470×200px；结论标签窄列换行变形；时间轴新图未接入样式循环呈黑底；左栏控件被宽度上限压窄。离屏渲染（1400×800）已复现。

## 目标
- 页签化主区：诊断图页签切换、单幅独占大幅面；优势观测结论横条与时间轴常驻。
- 修复时间轴黑底；结论数字 ≥18px 单行；左栏控件恢复可用宽度。

## 功能需求
- F1: 右栏重排为「结论横条（~112px）→ 诊断图 QTabWidget（主伸展）→ 时间轴（左右并排，~195px）→ 文本区（~120px）」。
- F2: 时间轴两图接入 `_init_plot_style` 浅色样式，消除黑底。
- F3: 结论横条大数字 ≥18px 加粗单行；按钮最小宽度；徽标与注记同行。
- F4: 左栏滚动区 360/470；combo 上限 260、spin/行编辑上限 140；间距加大。

## 非功能需求
- N1: 纯布局重排，不改功能行为、信号与数据流；观测引擎不动。
- N2: 测试引用的控件对象名全部保留。
- N3: 1400×900 无重叠/裁切/异常滚动；更小窗口左栏滚动兜底。

## 不做的事
- 不增删功能、不动引擎与后端、不改其他页签、不做换肤。

## 验收标准
- AC1: 离屏渲染 1400×800：四层边界清晰，页签单幅大幅面。
- AC2: 结论大数字单行无换行截断。
- AC3: 左栏输入控件 ≥140px、下拉 ≥220px，无标签换行。
- AC4: 现有测试全部通过（与基线一致）。
- AC5: 时间轴浅色底非黑。

- AC6: 两页签均为完整 2×2 四宫格，格子等大无挤压（截图验证）。
