# FDIDM 硬件实验证据闭环 Spec

## 背景

2026-09-07 的真实运行日志表明，当前硬件链路能够稳定同步并依靠 FEC 恢复文本，但平均 EVM 约为 45.7%、原始 BER 约为 4.5%、实测 SER 约为 9.6%。自适应控制器预测候选参数可改善约 0.67 dB，长期实测 SER 却没有改善；同时，不同 α/β 波形因峰值保护产生约 0.76 dB 的发射能量差，已经足以抵消预测收益。

同一次运行还暴露出三类平台问题：优势观测不会随硬件测试自动开始，参数热更新存在未初始化状态导致的界面异常，优势观测四宫格右下角与其他三个单元尺寸策略不一致。现有候选验证以切换前的单个瞬时指标作为基线，只要候选没有恶化超过门槛就标记为 accepted，不能证明候选确实带来优势。

因此本周期先闭合“功率公平 → 指标可信 → 窗口验证 → 页面展示 → 报告导出”的证据链，并补齐定位高 EVM 和高导频开销所需的诊断量。在这些证据可用前，不直接重写信道估计器，也不继续增加导频长度。

## 目标

- 启动一次硬件测试后，不需要额外的隐蔽操作即可看到优势观测数据；手动开关自适应能够自然形成固定参数窗口和候选参数窗口。
- 不同 α/β 的比较遵守明确的发射功率合同；功率不可比时不输出“FDIDM 实测优势”结论。
- 候选参数必须经过可比的多帧基线与候选窗口验证，结论区分“改善、无结论、退化”，不再把“未明显恶化”等同于“改善”。
- EVM、SER、FEC 与导频效率指标具有明确口径，能够判断问题来自链路质量、模型失配、功率回退还是样本不足。
- 优势观测页保持完整、等大的 2×2 四宫格，窗口汇总与三张时间图具有一致的视觉尺寸。

## 功能需求

- F1: 硬件测试进入运行态时自动建立一次观测会话，并以当时的自适应开关状态开始首个窗口。保留“重新开始观测”能力用于主动清空重测；测试停止时自动收尾并保留结果。
- F2: 手动开关自适应时，只有活动观测会话真正完成窗口切换后才显示“观测窗口已切换”；若会话不可用，应显示可操作的原因。参数热更新全路径不得因缺失的界面状态而中断。
- F3: 优势观测页四个单元采用一致的尺寸策略、外层容器和网格权重。右下角窗口汇总在常用窗口尺寸下与另外三个图等宽、等高，不因文本内容改变四宫格比例。
- F4: 每个发送波形对外报告实际平均功率、数据段平均功率、峰值、峰均比、相对目标功率回退和是否触发峰值保护。一次可比观测中的基线与候选必须使用相同的实际平均功率口径；若安全峰值限制导致功率差超出容差，应将该窗口对标记为功率不可比，而不是给出优势结论。
- F5: 实测指标同时提供基于已知发送符号的 data-aided EVM、判决导向 EVM、准确的 SER 错误数/总符号数、raw BER、FEC BER 与 CRC 成功率。界面和导出报告必须明确区分两种 EVM 以及预测 SER、实测 SER。
- F6: 接收诊断提供带明确含义的导频残差质量指标和模型失配指标。软件 TDL 的设定 SNR 不得显示成端到端实测 SNR；无法分离热噪声与模型残差时，指标必须以“残差 SINR/拟合误差”命名。
- F7: 候选验证使用切换前的多帧基线窗口和切换后的多帧候选窗口。切换瞬态、overflow、失步、上下文变化和功率不可比样本必须剔除；任一窗口样本不足时结果为“无结论”。
- F8: 验证输出三态结论：`improved`、`inconclusive`、`regressed`。只有实测主指标达到预设改善门槛且统计证据充分时才能进入 `improved`；预测收益只触发候选试验，不能决定实测结论。退化时回滚，无结论时默认回滚并保留原因。
- F9: 页面显示当前帧的导频、数据、同步/保护采样数以及有效数据占比。当前模式下导频与数据等长时应如实显示；选择高开销估计模式时必须在启动前提示训练/数据开销比，不通过继续增加导频来掩盖模型失配。
- F10: 日志与优势观测导出包含功率合同、两类 EVM、准确错误计数、验证窗口、剔除原因、三态结论、导频效率和模型残差指标，能够复核一次结论为何成立或不成立。

## 非功能需求

- N1: 保持单台 USRP 和现有射频安全峰值上限，不通过关闭峰值保护获取表面收益。
- N2: 新增统计、诊断和功率核算不得阻塞 GNU Radio/UHD 数据消费路径；可缓存的波形尺度和统计结果应复用。
- N3: 无 USRP、GNU Radio 或显示器时，功率公平、窗口验证、指标口径和页面接线能够离线自动测试。
- N4: 旧日志和缺失新增字段的模拟后端仍可被页面读取；缺字段时显示“不可用”，不得使刷新循环异常退出。
- N5: 结论以真实测量证据为准。FEC 后文本正确不能替代物理层质量结论，预测值、注入设定值和实测值不得混用。
- N6: 修改限定在 FDIDM 硬件发送、接收诊断、自适应验证和对应页面；不影响软波形仿真及其他硬件页面。

## 不做的事

- 本周期不实现新的稀疏、低秩或参数化复合信道估计器；先用新增证据完成 RF-only、静态 TDL、加噪声、加频偏/多普勒的分层定位。
- 不增加导频长度，不实现完整 `MN` 探测矩阵的实时化，也不宣称现有对角估计器已经适合所有双选择信道。
- 不增加自动增益控制、第二台 USRP、多波形硬件基线或自动定时 A/B 射频切换。
- 不以降低统计门槛、忽略功率回退或仅展示 FEC 后 BER 的方式制造优势。

## 验收标准

- AC1: 离屏端到端测试执行“启动硬件测试 → 固定参数采样 → 手动开启自适应 → 候选采样 → 停止测试”，无需另点开始观测即可得到两段窗口和结论；整个流程无界面属性异常。
- AC2: 1400×800、1400×900 和 1200×780 三档离屏几何测试中，优势页四个单元的宽高差在布局容差内，右下角文本多少不改变 2×2 比例。
- AC3: 构造两个 α/β 波形时，报告包含实际功率、峰值、PAPR 和回退；同一可比会话的平均功率差不超过既定容差。超过容差的模拟输入得到“功率不可比/无结论”，不会显示绿色优势。
- AC4: 已知注入符号错误和幅相扰动的离线测试中，data-aided EVM、判决导向 EVM、SER 错误数与总数均符合预期，且两种 EVM 标签不会混淆。
- AC5: 软件 TDL 设定为 35 dB 时，页面仍把其标为“注入设定”；导频残差质量以残差 SINR/拟合误差显示，不冒充端到端 SNR。
- AC6: 候选优于基线且样本充分时结论为 `improved`；差异不显著或样本不足时为 `inconclusive` 并回滚；候选显著恶化时为 `regressed` 并回滚。三种结果都有确定性测试。
- AC7: overflow、失步、上下文变化或功率差超限均能阻止无效窗口进入优势结论，并在页面、日志和导出报告中给出具体原因。
- AC8: 当前 `M=N=16、CP=4、diag-TF` 配置显示数据 320 点、导频 320 点及完整开销比例；切换估计模式后训练/数据比随实际帧结构更新。
- AC9: 复现 2026-09-07 日志中的“预测改善 0.67 dB、候选功率低约 0.76 dB、长期实测无改善”场景时，系统输出 `inconclusive` 或 `regressed`，不得输出“实测优势已验证”。
- AC10: 专项测试、FDIDM 硬件导入测试和全量测试完成；若存在改动前已知失败，报告必须逐项区分基线失败与本轮回归。
