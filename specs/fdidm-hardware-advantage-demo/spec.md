# FDIDM 硬件优势对比演示 Spec

## 背景

当前 FDIDM 硬件页能够显示频谱、星座、EVM、α/β 性能面和大量后端诊断，
但观众仍难以回答“软波形相比固定参数方案好在哪里”。本功能不增加第二套
USRP，也不恢复废弃的多波形硬件页，而是在同一台 USRP、同一套射频参数、同一
条收发链路上，按时间分阶段运行固定 α/β 基线和自适应 FDIDM，并把两阶段结果
整理成可读的证据。

## 目标

- 在单台 USRP 上完成固定参数基线与自适应 FDIDM 的时分对比。
- 让观众直接看到自适应是否降低实测 SER/EVM、提高 CRC/文本恢复成功率。
- 展示“信道变化 → α/β 推荐 → 参数应用 → 性能变化”的因果过程。
- 保留现有频谱、星座、α/β 性能面和详细诊断能力。
- 明确标注这是同链路时分基线，不声称并行或跨设备对比。

## 功能需求

- F1: 页面提供固定 α/β 基线参数、单阶段持续时间和交替轮数配置。
- F2: 用户点击开始后，系统在同一运行实例中按“固定基线 → 自适应 FDIDM”
  的顺序交替切换，所有阶段复用相同 USRP、频率、采样率、增益、消息、帧结构
  和功率归一化设置。
- F3: 固定基线阶段关闭 α/β 自动调整并使用指定 α/β；自适应阶段启用现有
  α/β 控制器，并从相同起始 α/β 开始。
- F4: 每个阶段记录处理帧数、CRC 成功率、文本匹配率、实测 SER、FEC BER、
  平均 EVM，并按阶段和模式汇总。
- F5: 页面显示基线与自适应的并列结果，以及改善量；样本不足或指标不可用时
  显示“暂无足够样本”，不得伪造结论。
- F6: EVM/性能时间图能够区分固定基线和自适应曲线，并标记阶段边界。
- F7: 页面显示当前阶段、剩余时间、已完成轮数和最近一次切换原因。
- F8: 对比结束后保留结果，允许继续观察实时链路；再次开始时清空旧对比结果。
- F9: 对比过程中的 α/β 切换使用现有 live update 路径，不因对比控制主动重启
  UHD；结构参数变化仍遵守原有受控重启规则。
- F10: 对比结果可写入现有 UI/后端日志，并随现有日志导出功能导出。

## 非功能需求

- N1: 不需要第二台 USRP、第二个 GNU Radio flowgraph 或并行射频链路。
- N2: 固定基线和自适应阶段必须复用相同发射功率配置；α/β 波形的 RMS 归一化
  和峰值安全限制保持不变。
- N3: 阶段切换不得阻塞 Qt UI 主线程；切换状态通过已有定时刷新机制推进。
- N4: 无硬件时页面仍可导入，核心汇总逻辑可通过离屏单元测试验证。
- N5: 不改变废弃的通用多波形硬件页，不实现 OFDM/OTFS/AFDM 的硬件基线。
- N6: 结果必须区分“模型预测 SER”和“真实接收测得 SER”，不可混用。

## 不做的事

- 不增加第二套发射机、接收机或同步运行的对比链路。
- 不把时分对比结果包装成严格同时刻的统计显著性结论。
- 不在本周期加入自动 RF 增益控制、自动信道预测或机器学习。
- 不恢复或扩展通用“硬件测评”页。
- 不把频谱、星座或单次 α/β 性能面作为唯一优势结论。

## 验收标准

- AC1: 在无硬件的离屏测试中，页面能够创建对比控件、初始化为空结果，并能
  对给定阶段样本计算基线/自适应汇总。
- AC2: 使用模拟后端运行两个阶段时，阶段顺序严格为基线、 自适应，并且每阶段
  记录的指标来自阶段内计数差值而非全局累计值。
- AC3: 汇总文本同时显示 CRC 成功率、实测 SER、平均 EVM 和改善量；指标无有效
  样本时显示明确的不可用提示。
- AC4: 对比性能图包含可区分的基线和自适应曲线，并保留阶段切换边界。
- AC5: 对比切换调用 live 配置路径；模拟后端能够证明未因 α/β 切换调用 stop/start。
- AC6: 对比完成后结果仍可见，再次开始会清空旧结果并重新计时。
- AC7: 现有硬件页导入测试和项目原有测试保持通过。
# 方向修订（2026-09-03）

本版本以“手动开启/关闭自适应后的连续链路观测”为准，废弃定时 baseline/adaptive 阶段对比。页面不宣称严格同信道因果实验，只展示真实链路中开启自适应后的可观测改善。
